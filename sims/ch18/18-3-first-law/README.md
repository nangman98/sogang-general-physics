# 18-3 열역학 제1법칙

교재 Principles of Physics 12e, Chapter 18, Module 18.5 The First Law of Thermodynamics 화면이다. 실린더 속 기체가 *p*–*V* 그림의 경로를 따라갈 때 기체가 한 일 *W*, 기체가 받은 열 *Q*, 내부 에너지 변화 Δ*E*<sub>int</sub>를 제1법칙으로 예측한다. 활동은 둘이고 둘 다 재생 전에 예측하고 채점한다.

| 활동 | 학생이 하는 일 | 교재 대응 |
|---|---|---|
| 두 경로 | 상태 i와 f의 압력과 부피, 구할 경로(ibf 또는 직선 if)를 정한다. 기준 경로 iaf의 열 *Q*<sub>iaf</sub>를 받아 구할 경로의 *W*와 *Q*를 적는다 | Eq. (18.5.2), (18.5.3), (18.5.6), Fig. 18.5.2a–c, LO 18.5.1–18.5.7, 18.5.9 |
| 순환 과정 | 같은 네 꼭짓점으로 된 직사각형 순환과 도는 방향을 정한다. 한 바퀴의 알짜 *W*와 알짜 *Q*를 적는다 | Eq. (18.5.2), (18.5.7), Fig. 18.5.2f, Table 18.5.1, LO 18.5.4, 18.5.10 |

## 모델

| 항목 | 내용 |
|---|---|
| 일 | 직선 구간마다 *W* = ∫*p* d*V*(식 18.5.2)를 사다리꼴 넓이의 닫힌 식으로 낸다. 구간 안 비율 *u*에서 *W*(*u*) = (*V*<sub>1</sub> − *V*<sub>0</sub>)[*p*<sub>0</sub>*u* + (*p*<sub>1</sub> − *p*<sub>0</sub>)*u*²/2]. 부피가 그대로인 구간은 *W* = 0이다 |
| 내부 에너지 | 경로마다 같은 Δ*E*<sub>int</sub>를 주려고 기체를 단원자 이상 기체로 두었다. *pV* = *nRT*(식 19.2.1)와 *E*<sub>int</sub> = (3/2)*nRT*(식 19.7.2)에서 *E*<sub>int</sub> = (3/2)*pV*다. 학생은 이 식을 쓰지 않고 기준 경로의 열과 "*Q* − *W*는 경로와 관계없다"는 18.5의 내용으로 푼다 |
| 열 | 구간마다 *Q* = Δ*E*<sub>int</sub> + *W*(식 18.5.3). 열 화살표 방향은 d*Q* = d*E*<sub>int</sub> + d*W*의 부호를 따른다. iaf에서 압력이 일정한 팽창 동안 열을 받고 부피가 일정한 압력 감소 동안 잃어 Fig. 18.5.2b의 설명과 같다 |
| 범위와 단위 | *p* 100–400 kPa, *V* 1.0–5.0 L. 1 kPa·L = 1 J이라 일과 열이 J로 나온다 |
| 가정 | 과정은 느려 기체가 늘 평형이다(Fig. 18.5.1). 벽은 단열이고 열은 바닥의 열저장체와만 주고받는다. 재생은 상태가 지나는 순서만 보여 주고 실제 시간이 아니라서 시간 막대를 숨겼다 |
| 채점 | 2% 또는 0.01 안이면 정답. 두 경로의 *W*는 부호를 바꾼 값, 기준 경로의 일, 직선 경로를 직사각형으로 센 값, 1000배 단위 실수를 따로 알려 준다. *Q*는 기준 경로의 열(경로와 무관하다고 본 값), Δ*E*<sub>int</sub> − *W*, 기준 경로에서 Δ*E*<sub>int</sub>의 부호를 바꾼 값, Δ*E*<sub>int</sub>를 뺀 *Q* = *W*, 1000배 단위 실수를 따로 알려 준다. 순환의 *W*는 부호를 바꾼 값, 한쪽 구간의 일, 크기를 더한 값을, *Q*는 0과 부호를 바꾼 값을 따로 알려 준다 |
| 시험 | `model.test.js` 6개. Sample Problem 18.5.1, 경로마다 넓이와 같은 *W*와 같은 Δ*E*<sub>int</sub>(3000칸 사다리꼴 합과 대조), 압축의 음의 일과 Table 18.5.1의 부피 일정·순환 경우, Fig. 18.5.2b의 열 부호와 열 변화율(중앙 차분), 재생의 처음과 끝, 채점과 기본값에서 실수 값이 정답과 2% 넘게 다름 |

Sample Problem 18.5.1(물 1.00 kg을 1.01 × 10⁵ Pa에서 끓임)은 같은 구간 식으로 *W* = 168.67 kJ ≈ 169 kJ을 확인한다. *Q* = *L*<sub>V</sub>*m* = 2256 kJ에서 Δ*E*<sub>int</sub> = 2087 kJ이고 교재는 2090 kJ로 적어 시험도 10 kJ 단위로 비교한다. 이 값은 시험에만 쓴다. 기본값(i = 300 kPa, 1.0 L, f = 100 kPa, 4.0 L)에서 *W*<sub>iaf</sub> = 900 J, *Q*<sub>iaf</sub> = 1050 J, Δ*E*<sub>int</sub> = 150 J이고 ibf는 *W* = 300 J, *Q* = 450 J, 직선 if는 *W* = 600 J, *Q* = 750 J, 순환 iafbi는 *W* = *Q* = 600 J이다. 영어 용어(first law of thermodynamics, work, heat, internal energy, p-V diagram, thermal reservoir, constant-volume process, cyclical process, closed cycle, path dependent)는 교재 `c18`에서 확인했다.
