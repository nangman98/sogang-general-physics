# 5-2 연결된 물체

교재 Principles of Physics 12e, Chapter 5, Module 5.3 Applying Newton’s Laws 화면이다. 활동은 둘이고 둘 다 재생 전에 움직이는 방향, 가속도 크기 *a*, 장력 *T*를 예측하고 채점한다.

| 활동 | 학생이 하는 일 | 교재 대응 |
|---|---|---|
| 애트우드 기계 | 도르래에 줄로 매단 블록 1, 2의 질량 *m*<sub>1</sub>, *m*<sub>2</sub>를 정한다. 어느 쪽이 내려가는지 고르고 *a*와 *T*를 적은 뒤 확인하고 재생한다 | Eq. (5.1.2), Atwood’s machine(Chapter 5 문제의 배치), LO 5.3.2 |
| 빗면 | 마찰 없는 빗면 위 미끄러지는 블록 S(질량 *M*)와 매단 블록 H(질량 *m*), 빗면 각 *θ*를 정한다. S가 빗면 위로 가는지 아래로 가는지 고르고 *a*와 *T*를 적는다. *θ* = 0이면 Sample Problem 5.3.1의 배치다 | Eq. (5.3.2), (5.3.6), (5.3.7), (5.3.8), LO 5.3.2 |

## 모델

| 항목 | 내용 |
|---|---|
| 애트우드 기계 | 블록 1 *T* − *m*<sub>1</sub>*g* = *m*<sub>1</sub>*a*, 블록 2 *T* − *m*<sub>2</sub>*g* = −*m*<sub>2</sub>*a*. *a* = (*m*<sub>2</sub> − *m*<sub>1</sub>)*g*/(*m*<sub>1</sub> + *m*<sub>2</sub>), *T* = 2*m*<sub>1</sub>*m*<sub>2</sub>*g*/(*m*<sub>1</sub> + *m*<sub>2</sub>). 블록 2가 내려가는 쪽이 양(+)이다 |
| 빗면 | S의 빗면 방향 *T* − *Mg* sin *θ* = *Ma*, H의 *T* − *mg* = −*ma*(식 5.3.6). *a* = (*m* − *M* sin *θ*)*g*/(*M* + *m*), *T* = *Mm*(1 + sin *θ*)*g*/(*M* + *m*). S가 빗면 위로 가는 쪽이 양(+)이다 |
| 가정 | 줄과 도르래는 질량이 없고(massless) 줄은 늘어나지 않는다. 도르래 축에 마찰이 없다(frictionless pulley). 빗면은 마찰이 없다. 블록은 정지에서 출발한다. *g* = 9.8 m/s² |
| 채점 | 방향은 정확히, *a*와 *T*는 2% 또는 0.01 안이면 정답. *a* = *g*, 질량 하나로만 나눈 *a*(애트우드), sin *θ*를 빼거나 cos *θ*로 쓴 *a*(빗면), 매단 블록의 무게와 같은 *T*는 따로 알려 준다 |
| 재생 | 애트우드 기계는 블록이 3.5 m, 빗면은 1.6 m를 가면(한 블록이 받침이나 도르래에 닿기 전) 멈춘다. 높은 받침은 학과의 이전 애트우드 실험실 방식이다. 이 화면은 재생 속도 1×로 시작한다. 두 블록이 비기면(*m*<sub>1</sub> = *m*<sub>2</sub> 또는 *m* = *M* sin *θ*) 정지해 있다 |
| 시험 | `model.test.js` 7개. Sample Problem 5.3.1(*a* = 3.8 m/s², *T* = 13 N, 식 5.3.4·5.3.6–5.3.9, 특수한 경우 *g* = 0, *M* = 0, *m* → ∞), 5.3.2(*mg* = 49.0 N, *a* = 0.100 m/s², 식 5.3.10), 빗면 두 식의 일치, 애트우드 두 식과 *T*가 두 무게 사이에 있는지, 채점, 재생 거리 |

Sample Problem 값은 시험에만 쓰고 화면에는 쓰지 않는다. 애트우드 기계는 교재 본문에 풀이가 없고 Chapter 5 문제 24, 58에 배치 이름(Atwood’s machine)만 나온다. 그래서 시험은 두 블록 식의 일치와 극한으로 대조했다. 영어 용어(Atwood’s machine, sliding block, hanging block, inclined plane, tension, gravitational force, normal force, massless, frictionless pulley, free-body diagram)는 교재 `c05`에서 확인했다.
