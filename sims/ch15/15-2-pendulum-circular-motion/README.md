# 15-2 진자와 원운동

교재 Principles of Physics 12e, Chapter 15, Module 15.4 Pendulums, Circular Motion 화면이다. 단진자와 막대 진자의 작은 각 근사 주기를 구하고 큰 진폭에서 실제 주기가 그보다 긴지 예측한다. 둘째 활동에서는 등속 원운동하는 기준 입자 P′의 *x*축 투영 P가 단순 조화 운동을 한다는 것을 보고 P의 처음 속도와 가속도를 구한다. 두 활동 모두 재생 전에 예측하고 채점한다.

| 활동 | 학생이 하는 일 | 교재 대응 |
|---|---|---|
| 진자 주기 | 진자 종류(단진자, 막대 진자), 길이 *L*, 각진폭 *θ*<sub>m</sub>을 정한다. 작은 각 근사 주기 *T*를 적고 실제 주기가 그보다 긴지, 1% 안에서 같은지, 짧은지 고른다 | Eq. (15.4.1)–(15.4.7), (15.4.10), Sample Problem 15.4.1, LO 15.4.1–15.4.7, 15.4.10 |
| 원운동과 SHM | 기준 원 반지름 *x*<sub>m</sub>, 각속력 *ω*, 위상 상수 *ϕ*를 정한다. *t* = 0일 때 투영 P의 속도 *v*와 가속도 *a*를 부호까지 적는다 | Eq. (15.4.13)–(15.4.15), (10.3.2), (10.3.7), Fig. 15.4.5, LO 15.4.11 |

## 모델

| 항목 | 내용 |
|---|---|
| 진자의 운동 방정식 | −*L*(*mg* sin *θ*) = *Iα*(Eq. 15.4.2), 막대는 *L* 대신 *h*. 둘 다 d²*θ*/d*t*² = −(*g*/*L*<sub>e</sub>) sin *θ*이고 *L*<sub>e</sub>는 단진자 *L*, 막대 *I*/(*mh*) = 2*L*/3(Eq. 15.4.7, *h* = *L*/2) |
| 작은 각 주기 | 단진자 *T* = 2π√(*L*/*g*)(Eq. 15.4.5), 막대 *T* = 2π√(*I*/*mgh*) = 2π√(2*L*/3*g*)(Eq. 15.4.6, 15.4.10). 막대의 진동 중심 *L*<sub>0</sub> = 2*L*/3(Eq. 15.4.12)을 확인 뒤 표시한다 |
| 실제 운동과 주기 | sin *θ*를 그대로 둔 위 방정식을 *θ*<sub>m</sub>에서 정지 상태로 한 주기 RK4(4000단계)로 풀어 표로 두고 3차 Hermite로 보간한다(8-1 진자와 같은 방법). 한 주기는 완전 타원 적분(산술–기하 평균)으로 구한 4√(*L*<sub>e</sub>/*g*) *K*(sin(*θ*<sub>m</sub>/2))다. 이 큰 진폭 주기는 교재에 없는 값이며 교재 운동 방정식을 수치로 풀어 얻었다. 시험에서 따로 돌린 고정 간격 RK4의 1/4 주기와 10⁻⁶ 안에서 맞는다 |
| 작은 각 근사 진자 | 확인 뒤 같은 길이의 반투명 진자가 *θ*<sub>m</sub> cos(2π*t*/*T*)로 함께 흔들린다 |
| 원운동 | P′은 돌림판 위 반지름 *x*<sub>m</sub>인 원을 위에서 볼 때 시계 반대 방향(+*x*에서 −*z* 쪽)으로 돈다. P는 *x* = *x*<sub>m</sub> cos(*ωt* + *ϕ*), *v* = −*ωx*<sub>m</sub> sin(*ωt* + *ϕ*), *a* = −*ω*²*x*<sub>m</sub> cos(*ωt* + *ϕ*)이고 P′의 속력 *ωx*<sub>m</sub>과 구심 가속도 *ω*²*x*<sub>m</sub>의 *x* 성분과 같다 |
| 범위 | *L* 0.5–3.0 m, *θ*<sub>m</sub> 5–80°. 작은 각 주기는 단진자 1.42–3.48 s, 막대 1.16–2.84 s다. 진자 재생은 주기와 상관없이 10 s 동안이다. 원운동은 *x*<sub>m</sub> 10–30 cm, *ω* 1.0–4.0 rad/s, *ϕ* 0–345°이고 두 바퀴를 되풀이한다 |
| 가정 | 줄과 막대는 늘어나지 않고 받침점 마찰과 공기 저항이 없다. *g* = 9.8 m/s² |
| 채점 | 2% 또는 0.01 안이면 정답. *T*는 √(*g*/*L*<sub>e</sub>)를 쓴 값, 2π를 뺀 1/*ω*, 진동수 *f*를 따로 알려 주고 막대에서는 길이 *L*인 단진자로 본 값과 길이 *h*인 단진자로 본 값도 알려 준다. 선택은 실제 주기가 작은 각 주기보다 1% 넘게 길면 "길다", 아니면 "1% 안에서 같다"가 정답이다. 경계는 *θ*<sub>m</sub> 22°(0.93%)와 23°(1.02%) 사이다. *v*(0)는 부호 반대, sin 대신 cos, *ω* 빠뜨림, P′의 속력 *ωx*<sub>m</sub>을, *a*(0)는 부호 반대, cos 대신 sin, *ω*² 대신 *ω*, P′의 가속도 크기 *ω*²*x*<sub>m</sub>을 따로 알려 준다 |
| 기본값 | 단진자 *L* = 1.2 m, *θ*<sub>m</sub> = 60°에서 *T* = 2.20 s, 실제 주기 2.36 s(1.073배). 막대는 *T* = 1.80 s, 실제 1.93 s. 원운동 *x*<sub>m</sub> = 20 cm, *ω* = 2.5 rad/s, *ϕ* = 60°에서 *v*(0) = −0.433 m/s, *a*(0) = −0.625 m/s². 실수 값은 모두 2% 넘게 다르다 |
| 시험 | `model.test.js` 7개. 막대의 *I*와 작은 각 주기(평행축 정리), Sample Problem 15.4.1, RK4 표가 운동 방정식(중앙 차분)과 에너지 보존을 만족하고 *T* 뒤 제자리, 타원 적분 주기와 따로 돌린 RK4의 일치, 작은 각 극한과 선택 정답의 1% 경계, 투영의 식 (15.4.13)–(15.4.15), 채점 |
