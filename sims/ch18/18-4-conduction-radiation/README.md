## 모델

| 항목 | 내용 |
|---|---|
| 전도 | 층마다 *P*<sub>cond</sub> = *kA*Δ*T*/*L*(식 18.6.1), *R* = *L*/*k*(식 18.6.2). 정상 상태에서 두 층의 전달률이 같아(식 18.6.3) *P*<sub>cond</sub> = *A*(*T*<sub>H</sub> − *T*<sub>C</sub>)/(*L*<sub>1</sub>/*k*<sub>1</sub> + *L*<sub>2</sub>/*k*<sub>2</sub>)(식 18.6.5)이고 *T*<sub>X</sub>는 식 18.6.4다. 층 번호는 Fig. 18.6.2처럼 뜨거운 쪽이 2, 차가운 쪽이 1이다. 모델 함수는 층이 몇 개든 식 18.6.6으로 푼다 |
| 복사 | *P*<sub>rad</sub> = *σεAT*⁴, *P*<sub>abs</sub> = *σεAT*<sub>env</sub>⁴, *P*<sub>net</sub> = *P*<sub>abs</sub> − *P*<sub>rad</sub>(식 18.6.7–18.6.9). *σ* = 5.6704 × 10⁻⁸ W/m²·K⁴, 온도는 *T* = *T*<sub>C</sub> + 273.15(식 18.2.1)로 켈빈으로 바꾼다. 공의 겉넓이는 *A* = 4π*r*²다 |
| 값 | 열전도율(W/m·K)은 Table 18.6.1의 15가지다. 스테인리스강 14, 납 35, 철 67, 황동 109, 알루미늄 235, 구리 401, 은 428, 건조한 공기 0.026, 헬륨 0.15, 수소 0.18, 폴리우레탄 폼 0.024, 암면 0.043, 유리 섬유 0.048, 소나무 목재 0.11, 창유리 1.0 |

| 가정 | 열은 판 면에 수직으로만 흐르고 옆으로 새지 않는다. 공과 주위의 온도는 고르다. 교재에 방사율 표가 없어 *ε*는 조절판으로 고른다. 대류는 다루지 않는다 |

| 시험 | `model.test.js` 5개. Sample Problem 18.6.1과 18.6.2, 두 층의 같은 전달률과 식 18.6.4, 18.6.5, 한 층의 식 18.6.1, 재료 225쌍에서 *T*<sub>X</sub>가 두 면 온도 사이에 있음, *T*⁴ 비례와 *T* = *T*<sub>env</sub>에서 *P*<sub>net</sub> = 0, 채점과 기본값에서 실수 값이 정답과 2% 넘게 다름 |

Sample Problem 18.6.1은 가운데 두 층의 *L*/*k*를 알 수 없어서 *T*<sub>2</sub> = 20 °C가 되도록 *L*/*k* = 2.8*L*<sub>a</sub>/*k*<sub>a</sub>로 두고 네 층을 식 18.6.6으로 풀어 *T*<sub>4</sub> = −8.0 °C를 확인한다. 교재의 닫힌 식 (*k*<sub>a</sub>*L*<sub>d</sub>/*k*<sub>d</sub>*L*<sub>a</sub>)(*T*<sub>1</sub> − *T*<sub>2</sub>) + *T*<sub>5</sub>도 같이 비교한다. Sample Problem 18.6.2는 교재가 *σ* = 5.67 × 10⁻⁸ W/m²·K⁴, 물의 비열 4190 J/kg·K, *T* ≈ 273 K를 써서 *P*<sub>net</sub> = −7.57 × 10⁻² W, *t* = 2.13 × 10⁴ s = 5.9 h를 얻으므로 시험도 그 값으로 계산한다. 화면은 본문의 *σ* = 5.6704 × 10⁻⁸와 273.15를 쓴다. Sample Problem 값은 화면 기본값으로 쓰지 않는다. 영어 용어(conduction, thermal conductivity, conduction rate, thermal resistance, R-value, composite slab, steady state, interface, thermal radiation, emissivity, Stefan–Boltzmann constant)는 교재 `c18`에서 확인했다.
