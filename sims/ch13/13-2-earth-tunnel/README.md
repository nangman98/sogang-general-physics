# 13-2 지구 속의 중력과 관통 터널

교재 Principles of Physics 12e, Chapter 13, Module 13.4 Gravitation Inside Earth 화면이다. 남극에서 북극까지 지구 중심을 지나는 터널(Fig. 13.4.1)에 캡슐을 떨어뜨린다. 학생은 재생 전에 지구 속 한 점에서 캡슐이 받는 중력과 중심을 지날 때의 속력을 구하고 채점받는다.

| 활동 | 학생이 하는 일 | 교재 대응 |
|---|---|---|
| 관통 터널 | 캡슐 질량 *m*과 힘을 물을 위치 *r*/*R*을 정한다. 그 위치의 중력 *F*와 중심에서의 속력 *v*를 적는다 | Eq. (13.4.1)–(13.4.4), (13.1.1), (7.4.6), (7.2.8), LO 13.4.1–13.4.2 |

## 모델

| 항목 | 내용 |
|---|---|
| 안쪽 질량과 힘 | *M*<sub>ins</sub> = *Mr*³/*R*³, 안에서 *F* = *GmMr*/*R*³, 밖에서 *F* = *GmM*/*r*² |
| 운동 | *F* = −*K r*(*K* = *GmM*/*R*³)라 *y*(*t*) = −*R* cos *ωt*, *ω* = √(*GM*/*R*³). 한 번 왕복이 5058 s(약 84 min)이고 교재 13.4에는 이 값이 없어 모델에서 계산했다 |
| 중심 속력 | 용수철 꼴 힘의 일 ½*KR*²(Eq. 7.4.6)과 일–운동에너지 정리(Eq. 7.2.8)로 *v* = √(*GM*/*R*) = 7.91 km/s |
| 가정 | 밀도가 고르고 돌지 않는 지구, *M* = 5.98 × 10²⁴ kg, *R* = 6370 km. 터널에 마찰과 공기 저항이 없다 |
| 채점 | 2% 또는 0.01 안이면 정답. 지구 전체 질량을 넣은 *GmM*/*r*², 지표 무게 *mg*, 일정한 중력으로 구한 √(2*gR*), m/s 단위를 따로 알려 준다 |
| 시험 | `model.test.js` 4개. 안쪽 질량으로 구한 힘과 식 (13.4.3)의 일치, 거리에 비례, 지표에서 식 (13.1.1)과 연결, 운동이 *m* d²*y*/d*t*² = −*Ky*를 만족하고 반 주기에 북극 도달, ½*mv*² = ½*KR*², 채점 |

Module 13.4에는 Sample Problem이 없다. 영어 용어(uniform shell, uniform solid sphere, inside mass, Hooke's law)는 교재 `c13`에서 확인했다.
