# 11-3 요요

교재 Principles of Physics 12e, Chapter 11, Module 11.3 The Yo-Yo 화면이다. 줄을 따라 내려가는 요요의 가속도와 장력을 재생 전에 구하고 채점한다. 요요는 빗면 각 90°에서 축 반지름 *R*<sub>0</sub>로 구르는 물체로 다룬다(LO 11.3.2).

| 활동 | 학생이 하는 일 | 교재 대응 |
|---|---|---|
| 요요 하나 | 질량 *M*, 바깥 반지름 *R*, 축 반지름 *R*<sub>0</sub>를 정한다. 가속도 크기 \|*a*<sub>com</sub>\|와 장력 *T*를 적는다 | Eq. (11.3.1), LO 11.3.1–11.3.4 |

## 모델

| 항목 | 내용 |
|---|---|
| 가속도 | *I*<sub>com</sub> = ½*MR*², \|*a*<sub>com</sub>\| = *g*/(1 + *I*<sub>com</sub>/*MR*<sub>0</sub>²) (Eq. 11.3.1) |
| 장력 | *T* = *M*(*g* − \|*a*<sub>com</sub>\|), 각가속도 *α* = \|*a*<sub>com</sub>\|/*R*<sub>0</sub> |
| 가정 | 요요는 반지름 *R*인 고른 원판, 축 질량 무시. 줄은 가볍고 늘어나지 않으며 축에서 미끄러지지 않는다. 정지에서 1.6 m를 내려간다. *g* = 9.8 m/s² |
| 채점 | 2% 또는 0.01 안이면 정답. 자유 낙하 *g*, 축 대신 바깥 반지름으로 굴린 *g*/1.5, *T* = *Mg*를 따로 알려 준다. 기본값(*M* = 0.12 kg, *R* = 3.0 cm, *R*<sub>0</sub> = 0.6 cm)에서 *T*와 *Mg*는 8% 다르다 |
| 시험 | `model.test.js` 3개. 직선 운동과 회전의 제2법칙 일치(*Mg* − *T* = *Ma*, *TR*<sub>0</sub> = *I*<sub>com</sub>*α*, *a* = *αR*<sub>0</sub>), *R*<sub>0</sub> = *R*에서 *g*/1.5, 에너지 보존 *Mgh* = ½*Mv*² + ½*I*<sub>com</sub>*ω*², 채점과 cm → m 변환 |

Module 11.3에는 Sample Problem이 없다. 영어 용어(yo-yo, axle, rotational inertia, free-body diagram, tension)는 교재 `c11`에서 확인했다.
