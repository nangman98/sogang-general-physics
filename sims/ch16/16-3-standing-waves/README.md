# 16-3 정상파와 공명

교재 Principles of Physics 12e, Chapter 16, Module 16.7 Standing Waves and Resonance 화면이다. 양 끝이 고정된 줄의 공명 진동수와 파장, 그리고 반대로 가는 두 진행파가 만든 정상파에서 한 줄 요소의 진폭과 최대 가로 속력을 재생 전에 예측하고 채점한다. 활동은 둘이다.

| 활동 | 학생이 하는 일 | 교재 대응 |
|---|---|---|
| 공명 진동수 | 줄 길이 *L*, 장력 *τ*, 선밀도 *μ*, 배음 번호 *n*을 정한다. 그 진동 모드의 파장 *λ*와 공명 진동수 *f*를 적는다 | Eq. (16.2.5), (16.7.5), (16.7.8), (16.7.9), Sample Problem 16.7.1, Checkpoint 16.7.2, LO 16.7.6–16.7.8 |
| 마디와 배 | 길이 3.00 m, *v* = 6.00 m/s인 줄에서 배음 번호 *n*, 진행파의 진폭 *y*<sub>m</sub>, 줄 요소의 위치 *x*를 정한다. 그 요소의 진폭과 최대 가로 속력 *u*<sub>max</sub>를 적는다 | Eq. (16.7.1)–(16.7.3), (16.7.5), (16.7.7), LO 16.7.1–16.7.4 |

## 모델

| 항목 | 내용 |
|---|---|
| 정상파 | *y*<sub>1</sub> = *y*<sub>m</sub> sin(*kx* − *ωt*), *y*<sub>2</sub> = *y*<sub>m</sub> sin(*kx* + *ωt*), *y*′ = [2*y*<sub>m</sub> sin *kx*] cos *ωt*. 마디는 *x* = *nλ*/2, 배는 *x* = (*n* + ½)*λ*/2 |
| 공명 | *v* = √(*τ*/*μ*), *λ* = 2*L*/*n*, *f* = *v*/*λ* = *nv*/2*L*. 왼쪽 끝의 진동자는 진폭을 무시해 고정된 끝(마디)으로 다룬다 |
| 줄 요소 | 진폭 \|2*y*<sub>m</sub> sin *kx*\|, *u* = ∂*y*′/∂*t* = −[2*y*<sub>m</sub> sin *kx*]*ω* sin *ωt*(식 16.7.3을 *t*로 미분), *u*<sub>max</sub> = *ω*\|2*y*<sub>m</sub> sin *kx*\| |
| 범위 | 공명 활동은 *L* = 2.0–5.0 m, *τ* = 5–20 N, *μ* = 200–800 g/m, *n* = 1–6. 마디와 배 활동은 *L* = 3.00 m, *τ* = 9.0 N, *μ* = 250 g/m 고정, *n* = 1–5, *y*<sub>m</sub> = 3–12 cm, *x* = 0–300 cm |
| 그림 진폭 | 공명 진동수는 진폭과 관계없어 공명 활동의 배 진폭은 그림에서 0.20 m와 *λ*/8 중 작은 값으로 정했다 |
| 재생 | 한 주기가 화면에서 1.6 s가 되도록 `timeScale`을 진동 모드마다 *T*/1.6 s로 정한다(주기가 1.6 s보다 길면 실제 빠르기). 기본값에서 공명 활동은 0.245배, 마디와 배 활동은 0.208배 빠르기다. 가정 목록에 몇 배 느린지 적는다. `dt` = 10⁻⁴ s |
| 채점 | 2% 또는 0.01 안이면 정답. 파장 *L*/*n*(고리 하나를 한 파장으로 봄)과 2*L*(*n*을 무시), 진동수 *nv*/*L*, *v*/2*L*, g/m를 그대로 쓴 값, *vλ*, 진폭 2*y*<sub>m</sub>(위치와 무관하다고 봄), *y*<sub>m</sub>\|sin *kx*\|, 2*y*<sub>m</sub>\|cos *kx*\|, *kx*를 도로 읽은 값, 속력 *v*, *fA*, 배의 속력 2*y*<sub>m</sub>*ω*, *ω*²*A*, cm 그대로 쓴 값을 따로 알려 준다. 기본값에서 정답과 각 실수 값은 2% 넘게 다르다 |
| 시험 | `model.test.js` 6개. Sample Problem 16.7.1, Checkpoint 16.7.2의 배음 열(75, 150, 225, 300, 375 Hz와 525 Hz), 두 진행파의 합과 식 (16.7.3)의 일치, 마디의 변위 0, 배의 진폭 2*y*<sub>m</sub>, 마디 간격 *λ*/2, 줄 요소의 *u* = ∂*y*′/∂*t*(중앙 차분)와 *u*<sub>max</sub>, 재생 빠르기, 채점 |

Sample Problem 값은 시험에만 쓰고 화면에는 쓰지 않는다. 16.7.1은 *f* = 3*v*/2*L*에서 *v* = 12.5 m/s, *τ* = *μv*² = 5.85 × 10⁻² N을 구하고 그 줄의 모델 공명 진동수가 62.0 Hz, *T* = 16.1 ms, *λ* = 20.2 cm임을 확인한다. 교재 값과 표시 자릿수에서 모두 같다. 영어 용어(standing wave, node, antinode, resonant frequency, oscillation mode, harmonic number, loop, oscillator)는 교재 `c16`에서 확인했다.
