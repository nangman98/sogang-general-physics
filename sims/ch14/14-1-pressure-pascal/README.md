# 14-1 깊이에 따른 압력과 파스칼 원리

교재 Principles of Physics 12e, Chapter 14, Module 14.2 Fluids at Rest, 14.3 Measuring Pressure, 14.4 Pascal's Principle 화면이다. 열린 수조 속 압력이 깊이에 따라 커지는 것과 유압 지렛대에서 압력 변화가 그대로 전달되는 것을 본다. 활동은 둘이고 둘 다 재생 전에 예측하고 채점한다.

| 활동 | 학생이 하는 일 | 교재 대응 |
|---|---|---|
| 깊이와 압력 | 액체(물, 바닷물, 수은)와 탐침 깊이 *h*를 정한다. 계기 압력과 절대 압력을 kPa로 적는다 | Eq. (14.2.4), Table 14.1.1, LO 14.2.1–14.2.2 |
| 유압 지렛대 | 두 피스톤 넓이 *A*<sub>i</sub>, *A*<sub>o</sub>, 입력 힘 *F*<sub>i</sub>, 입력 거리 *d*<sub>i</sub>를 정한다. 출력 힘 *F*<sub>o</sub>와 출력 거리 *d*<sub>o</sub>를 적는다 | Eq. (14.4.2)–(14.4.5), LO 14.4.1–14.4.2 |

## 모델

| 항목 | 내용 |
|---|---|
| 깊이 | *p* = *p*<sub>0</sub> + *ρgh*, 계기 압력 *ρgh*. *ρ*는 Table 14.1.1(물 998, 바닷물 1024, 수은 13.6 × 10³ kg/m³), *p*<sub>0</sub> = 1.01 × 10⁵ Pa |
| 유압 | *F*<sub>o</sub> = *F*<sub>i</sub>*A*<sub>o</sub>/*A*<sub>i</sub>, *d*<sub>o</sub> = *d*<sub>i</sub>*A*<sub>i</sub>/*A*<sub>o</sub>, *W* = *F*<sub>o</sub>*d*<sub>o</sub> = *F*<sub>i</sub>*d*<sub>i</sub> |
| 재생 | 탐침이나 입력 피스톤이 3 s 동안 고르게 움직인다 |
| 채점 | 2% 또는 0.01 안이면 정답. 계기 압력 자리에 쓴 절대 압력, *g*를 뺀 값, 대기압을 뺀 절대 압력, 넓이 비를 거꾸로 쓴 힘과 거리, 입력과 같은 힘과 거리를 따로 알려 준다 |
| 시험 | `model.test.js` 3개. Table 14.1.1 값과 식 (14.2.4), 물 10 m가 약 1 atm이고 수은 0.76 m가 1 atm(오차 4%, 1%), 힘 증폭과 부피 보존과 같은 일, 두 피스톤의 같은 압력 변화, 채점 |

Module 14.2의 Sample Problem 14.2.1(U자관)은 다루지 않았다. 영어 용어(gauge pressure, absolute pressure, Pascal's principle, hydraulic lever)는 교재 `c14`에서 확인했다.
