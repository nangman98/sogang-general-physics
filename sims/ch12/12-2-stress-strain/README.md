# 12-2 응력과 변형률, 영률

교재 Principles of Physics 12e, Chapter 12, Module 12.3 Elasticity 화면이다. 한쪽 끝이 고정된 막대의 끝면에 힘을 가해 응력과 길이 변화를 구한다. 응력–변형률 그래프에서는 선형 구간과 항복 강도·극한 강도를 본다. 학생은 재생 전에 예측하고 채점받는다.

| 활동 | 학생이 하는 일 | 교재 대응 |
|---|---|---|
| 인장과 압축 | 재료, 막대 반지름 *R*, 길이 *L*, 힘 *F*를 정한다. 응력 *F*/*A*와 길이 변화 Δ*L*을 적는다 | Eq. (12.3.1), (12.3.2), Table 12.3.1, Sample Problem 12.3.1, Fig. 12.3.5, LO 12.3.2–12.3.3 |

## 모델

| 항목 | 내용 |
|---|---|
| 응력과 변형률 | *A* = π*R*², *F*/*A* = *E* Δ*L*/*L*(Eq. 12.3.2) |
| 재료 | Table 12.3.1의 *E*, *S*<sub>u</sub>, *S*<sub>y</sub>. 강철 200·400·250, 알루미늄 70·110·95, 폴리스타이렌 3·48, 유리 65·50, 콘크리트 30·40, 나무 13·50, 뼈 9·170(*E*는 10⁹ N/m², 강도는 10⁶ N/m²). 유리·콘크리트·나무·뼈는 표의 강도가 압축 값이라 막대를 누른다 |
| 힘의 범위 | 응력이 선형 구간에 머물도록 *F*의 최댓값을 *S*<sub>y</sub>*A*(표에 없으면 *S*<sub>u</sub>*A*)로 막았다. 그 너머의 영구 변형은 다루지 않는다 |
| 재생 | 힘이 0에서 *F*까지 3 s 동안 고르게 커진다 |
| 채점 | 2% 또는 0.01 안이면 정답. 지름으로 넓이를 구한 값, π를 뺀 값, 단위를 1000배 틀린 값, 변형률을 길이 변화로 적은 값을 따로 알려 준다 |
| 시험 | `model.test.js` 4개. Sample Problem 12.3.1(2.2 × 10⁸ N/m², Δ*L* = 0.89 mm, 변형률 1.1 × 10⁻³), Table 12.3.1 값과 모든 재료·반지름에서 힘 최댓값이 선형 구간 안에 있는지, 힘을 키우는 동안 식 (12.3.2)와 길이에 무관한 변형률, 채점 |

Sample Problem 값은 시험에만 쓰고 화면에는 쓰지 않는다. 표의 각주(강철은 ASTM-A36, 콘크리트는 고강도, 나무는 Douglas fir, b는 압축 값)를 재료 이름과 가정에 옮겼다. 영어 용어(stress, strain, Young's modulus, yield strength, ultimate strength)는 교재 `c12`에서 확인했다.
