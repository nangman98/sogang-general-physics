# 15-3 감쇠 진동

교재 Principles of Physics 12e, Chapter 15, Module 15.5 Damped Simple Harmonic Motion 화면이다. 액체 속 날개(vane)가 달린 용수철–블록 진동자(Fig. 15.5.1)에서 진폭이 절반이 되는 시각과 역학적 에너지가 절반이 되는 시각을 재생 전에 구하고 채점한다. 확인 뒤 *x*–*t* 그래프와 진폭 곡선, 열에너지로 옮겨 가는 에너지 막대가 나타난다.

| 활동 | 학생이 하는 일 | 교재 대응 |
|---|---|---|
| 감쇠 진동자 | 질량 *m*, 용수철 상수 *k*, 감쇠 상수 *b*, 처음 진폭 *x*<sub>m</sub>을 정한다. 진폭이 절반이 되는 시각과 역학적 에너지가 절반이 되는 시각을 적는다 | Eq. (15.5.1)–(15.5.6), Fig. 15.5.1, 15.5.2, Sample Problem 15.5.1, LO 15.5.1–15.5.5 |

## 모델

| 항목 | 내용 |
|---|---|
| 운동 | *F*<sub>d</sub> = −*bv*, −*bv* − *kx* = *ma*의 해 *x*(*t*) = *x*<sub>m</sub>*e*<sup>−*bt*/2*m*</sup> cos(*ω*′*t* + *ϕ*), *ω*′ = √(*k*/*m* − *b*²/4*m*²). 닫힌 식이라 적분하지 않는다. *ϕ* = 0이라 Fig. 15.5.2처럼 *x* = *x*<sub>m</sub>에서 시작한다(식 15.5.4가 주는 처음 속도 −*bx*<sub>m</sub>/2*m*을 그대로 둔다) |
| 에너지 | 식 (15.5.6) *E*(*t*) ≈ ½*kx*<sub>m</sub>²*e*<sup>−*bt*/*m*</sup>. 막대는 *x*, *v*로 구한 정확한 *K* + *U*를 쓰고 처음 에너지에서 줄어든 만큼을 늘어난 열에너지 Δ*E*<sub>th</sub>로 둔다. 이 값은 감쇠력이 한 일 ∫*bv*² d*t*와 같다 |
| 물은 시각 | 진폭 *x*<sub>m</sub>*e*<sup>−*bt*/2*m*</sup> = *x*<sub>m</sub>/2에서 *t* = 2*m* ln 2/*b*, 식 (15.5.6)에서 *t* = *m* ln 2/*b*. 둘 다 교재 식 (15.5.4), (15.5.6)에서 바로 나온다 |
| 범위 | *m* 0.20–1.00 kg, *k* 10–40 N/m, *b* 0.05–0.50 kg/s(아래 끝은 0.25*m* kg/s), *x*<sub>m</sub> 5–15 cm. 진폭이 절반이 되는 시각은 0.555–5.55 s라 언제나 재생 12 s 안에 있다. 이 범위에서 *k*/*m* > *b*²/4*m*²라 *ω*′가 실수다 |
| 가정 | 감쇠력은 속도에 비례하고 막대와 날개의 질량은 무시한다. 교재처럼 블록의 중력은 무시하고 *x*는 평형 위치에서 위를 +로 잰다. 재생은 설정과 상관없이 12 s 동안이라 시간 축 끝으로 답이 드러나지 않는다 |
| 채점 | 2% 또는 0.01 안이면 정답. 진폭 쪽은 에너지가 절반이 되는 시각, 상용로그로 구한 값, ln 2를 뺀 2*m*/*b*를, 에너지 쪽은 진폭이 절반이 되는 시각, 상용로그 값, *m*/*b*를 따로 알려 준다. 기본값(*m* = 0.40 kg, *k* = 25 N/m, *b* = 0.12 kg/s, *x*<sub>m</sub> = 10 cm)에서 답은 4.62 s, 2.31 s이고 실수 값(2.31, 2.01, 6.67 / 4.62, 1.00, 3.33 s)은 모두 2% 넘게 다르다 |
| 시험 | `model.test.js` 7개. 중앙 차분으로 식 (15.5.3)과 *v* = d*x*/d*t* 확인, *b* → 0에서 *ω*′ = √(*k*/*m*), 두 절반 시각과 진폭 곡선 안의 *x*, 에너지 수지 *K* + *U* + ∫*bv*² d*t* = 처음 에너지(Simpson 적분, 10⁻⁶), 한 주기 평균 *K* + *U*와 식 (15.5.6)의 1% 일치, Sample Problem 15.5.1, 슬라이더 범위, 채점 |

Sample Problem 15.5.1(√(*km*) = 4.6 kg/s, *T* = 0.34 s, 진폭 절반 5.0 s, 에너지 절반 2.5 s, 약 15주기)은 시험에만 쓰고 화면 기본값으로 쓰지 않는다. 영어 용어(damping force, damping constant, vane, rigid support, angular frequency, mechanical energy, thermal energy)는 교재 `c15`에서 확인했다.
