## 모델

| 항목 | 내용 |
|---|---|
| 궤도 | *E* = ½*mv*² − *GMm*/*r* = −*GMm*/2*a*, *T*² = (4π²/*GM*)*a*³. *f* > 1이면 P가 근지점, *f* < 1이면 원지점이고 반대편 끝은 2*a* − *r*에 있다 |
| 궤도 위 위치 | 케플러 방정식 *M* = *E* − *e* sin *E*를 Newton 방법으로 풀어 시간에 따른 위치를 닫힌 식으로 구한다 |
| 범위 | *h* = 300–3000 km, *f* ≤ 1.25. *f*의 아래 끝은 근지점이 지표에서 100 km 위에 있도록 높이에 따라 정한다 |
| 탈출 | *v* = √(2*GM*/*R*), *r*<sub>max</sub> = *R*/(1 − *f*²). 곧게 위로 올라갔다 내려오는 운동은 *r* = *r*<sub>max</sub>(1 − cos *η*)/2, *t* = √(*r*<sub>max</sub>³/8*GM*)(*η* − sin *η*)로 구한다. 탈출 속력으로 쏜 물체는 *r*<sup>3/2</sup> = *R*<sup>3/2</sup> + (3/2)√(2*GM*) *t* |
| 상수 | *G* = 6.67 × 10⁻¹¹ N·m²/kg², 지구 *M* = 5.98 × 10²⁴ kg, *R* = 6370 km, 위성 질량 1000 kg |
| 채점 | 2% 또는 0.01 안이면 정답. 점화 전 주기, 초 단위 주기, 반대편 끝 거리로 구한 주기, 중심에서 잰 거리, *a* − *R*, 2를 뺀 √(*GM*/*R*), 균일한 *g*로 구한 높이 *f*²*R*, 중심에서 잰 *r*<sub>max</sub>/*R*를 따로 알려 준다 |
| 시험 | `model.test.js` 6개. Table 13.5.1 탈출 속력 네 개(1% 안), Sample Problem 13.7.1(−214 MJ, −451 MJ), 13.7.2(*a* = 7.418 × 10⁶ m 안 0.003 × 10⁶ m, *T* = 106 min), 궤도 위 에너지 보존과 *r*<sub>a</sub> + *r*<sub>p</sub> = 2*a*, 근지점과 원지점에서 시작한 같은 시간 넓이의 일치와 d*A*/d*t* = *L*/2*m*, 탈출 운동의 *r*<sub>max</sub>와 중앙 차분 d²*r*/d*t*² = −*GM*/*r*², 채점 |

Sample Problem 13.7.2는 *v*<sub>0</sub>를 2π*r*/*T*<sub>0</sub>(*T*<sub>0</sub> = 7.119 × 10³ s)로 구한다. 모델은 √(*GM*/*r*)를 써서 0.004% 다르고 시험은 그 차이를 허용한다. Sample Problem 값은 시험에만 쓰고 화면에는 쓰지 않는다. 영어 용어(escape speed, law of areas, law of periods, semimajor axis, perigee, apogee)는 교재 `c13`에서 확인했다.
