# 3-1 성분 분해와 벡터 덧셈

교재 Principles of Physics 12e, Chapter 3, Module 3.1 Vectors and Their Components와 Module 3.2 Unit Vectors, Adding Vectors by Components 화면이다. 활동은 셋이고 채점하는 활동이 둘이다.

| 활동 | 학생이 하는 일 | 교재 대응 |
|---|---|---|
| 성분 분해 | *a<sub>x</sub>*, *a<sub>y</sub>*, *a<sub>z</sub>*를 정하면 *a⃗*, 축 위의 성분 화살표(점선), 대각선이 *a⃗*인 상자, xy 평면의 각 *θ*가 그려진다. 좌표축 회전 *ϕ*를 주면 *x*′, *y*′ 축의 성분만 바뀌고 *a⃗*와 크기는 그대로다 | Eq. (3.1.5), (3.1.6), (3.2.1), (3.2.8), (3.2.9), LO 3.1.3–3.1.5, 3.2.1, 3.2.3 |
| 벡터 덧셈 | 꼬리를 모아 그린 *a⃗*, *b⃗* 옆의 후보 ①–③ 가운데 *s⃗* = *a⃗* + *b⃗*를 먼저 고른다. 확인하면 *b⃗*가 머리–꼬리로 붙고 *s⃗*가 그려진다. 재생하면 드론이 *a⃗*, *b⃗*를 차례로 난다. 순서 바꿔 더하기와 뺄셈 보기를 켤 수 있다 | Eq. (3.1.1), (3.1.2), (3.1.4), LO 3.1.1(교환 법칙까지), 3.1.2 |
| 성분 계산 | 9문제. 크기–각에서 성분의 부호와 값, 성분에서 크기와 각, 성분별 합과 차, 세 성분에서 크기를 구한다. 확인하면 답이 장면에 그려진다 | Eq. (3.1.5), (3.1.6), (3.2.4)–(3.2.7), LO 3.1.3, 3.1.4, 3.2.1, 3.2.2 |

결합 법칙(Eq. 3.1.3)은 다루지 않아 LO 3.1.1은 교환 법칙까지만 대응한다고 적었다.

## 모델

| 항목 | 내용 |
|---|---|
| 각 | +*x* 방향에서 시계 반대 방향이 양이다(교재 Tactic 1). 화면은 (−180°, 180°]로 보이고 채점은 360°의 정수배만큼 다른 각을 같은 각으로 본다 |
| 계산기 함정 | tan⁻¹(*a<sub>y</sub>*/*a<sub>x</sub>*)는 −90°에서 90° 사이만 준다. *a<sub>x</sub>* < 0이면 장면 아래 글과 피드백이 180°를 더하거나 빼라고 알린다(Tactic 3, Sample Problem 3.2.2) |
| 3차원 크기 | *a* = √(*a<sub>x</sub>*² + *a<sub>y</sub>*² + *a<sub>z</sub>*²). 교재는 Sample Problem 3.1.1에서 피타고라스 정리를 두 번 쓰고 번호를 붙이지 않는다. 화면에도 번호 없이 적었다 |
| 식 (3.1.5), (3.1.6) | 교재 KEY IDEAS대로 xy 평면 위 벡터의 식이다. 식 아래에 *a<sub>z</sub>* = 0 조건을 적었다 |
| 식 (3.2.1) | 본문은 2차원 꼴이고 KEY IDEAS와 Review & Summary는 같은 번호의 3차원 꼴이다. 화면은 3차원 꼴이다 |
| 덧셈 후보 | ①–③은 *s⃗*, *a⃗* − *b⃗*, *b⃗* − *a⃗*다. *b⃗* − *a⃗*는 꼬리를 모은 두 벡터의 머리끼리 이은 화살표와 같다. 번호 순서는 벡터 값에 따라 바뀐다 |
| 드론 비행 | 0–1.6 s *a⃗*, 1.6–3.2 s *b⃗*, 3.2–3.8 s *s⃗*를 그린다. *a⃗*를 나는 동안 드론이 *b⃗*의 꼬리를 싣고 가서 머리–꼬리 배치가 된다. 조절값을 바꾸면 처음(*t* = 0)으로 돌아간다 |
| 판 크기 | 성분 분해 ±3.5 m, 성분 계산 ±5 m, 벡터 덧셈은 벡터에 맞춰 ±4–7 m다. 조절값을 바꿀 때만 다시 정한다(05 §무대) |
| 채점 | 값은 1% 또는 0.03 m 안, 각은 1° 안이면 정답이다. 부호 실수, cos와 sin 바뀜, 계산기의 사분면 오류, 합 대신 차, *z* 성분 누락은 따로 알려 준다 |
| 시험 | `model.test.js` 13개 |

## 색과 선 모양

| 대상 | 색 | 선 모양과 글자 |
|---|---|---|
| *a⃗* | #0072B2 | 굵은 실선 화살표, 머리 옆 KaTeX *a⃗* |
| *b⃗* | #D55E00 | 굵은 실선 화살표, 옮기기 전 자리는 옅게 남긴다 |
| *s⃗*, *r⃗* (합) | #009E73 | 다른 벡터보다 굵은 실선 |
| *d⃗* (차) | #CC79A7 | 실선, 뺄셈 보기를 켤 때만 |
| 성분 | 그 벡터와 같은 색 | 점선 화살표와 값 태그 |
| 단위 벡터 *î*, *ĵ*, *k̂* | #000000 | 길이 1 m, 측정대 왼쪽 앞 모서리. 원점에 두면 양의 성분 화살표와 겹쳐서 옮겼다 |
| 후보 ①–③ | #8D9AA7 | 가는 회색 화살표와 번호 |

*a⃗*, *b⃗*, 합은 특정 물리량이 아니어서 05 §색의 다섯 색 가운데 서로 다른 셋을 골랐다. 다섯 색 모두 흰 바탕 대비가 3 이상이다(05 §색). 색만으로 가르지 않도록 모든 화살표 머리에 이름을 달았다. 합은 더 굵은 화살표다. 성분은 점선 화살표다.
