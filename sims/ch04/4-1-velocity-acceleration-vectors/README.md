# 4-1 곡선 경로의 평균·순간 속도와 가속도

교재 Principles of Physics 12e, Chapter 4, Module 4.2 Average Velocity and Instantaneous Velocity와 Module 4.3 Average Acceleration and Instantaneous Acceleration 화면이다. 제목의 괄호 영어는 두 module 제목이다. 드론이 3D 곡선 경로를 날고 평균 속도와 평균 가속도가 Δ*t* → 0에서 순간값으로 가는 과정을 보인다. 활동은 셋이다.

| 활동 | 학생이 하는 일 | 교재 대응 |
|---|---|---|
| 평균 속도 | 경로와 Δ*t*를 고르고 재생하거나 시간을 옮긴다. 점 1, 점 2, *r⃗*₁, *r⃗*₂, Δ*r⃗*, *v⃗*avg, *v⃗*가 함께 움직인다. "Δt 줄이기" 단추가 Δ*t*를 3 s에서 0.05 s까지 줄이고 표가 Δ*t* = 2, 1, 0.5, 0.1, 0.01 s의 \|*v⃗*avg\|와 *v⃗*와의 사이 각을 보인다 | Eq. (4.1.2), (4.2.1), (4.2.3)–(4.2.5), LO 4.2.1–4.2.3 |
| 평균 가속도 | 점 1과 점 2의 *v⃗*₁, *v⃗*₂를 꼬리끼리 모아 Δ*v⃗*를 만들고 *a⃗*avg = Δ*v⃗*/Δ*t*가 *a⃗*로 가는 것을 본다. 나선 비행은 속력이 일정해도 가속도가 있음을, 등가속도 비행은 *a⃗*가 경로 어디서나 같음을 보인다 | Eq. (4.3.1)–(4.3.4), LO 4.3.1–4.3.3 |
| 방향 예측 | 점 P에서 나온 회색 화살표 넷 가운데 *v⃗*의 방향을 고르고 확인한 뒤 *a⃗*의 방향을 고른다. 고른 오답마다 그 화살표가 무엇인지 알려 준다 | Key Idea 4.2의 3번(접선 방향), LO 4.2.2, 4.3.2 |

## 모델

| 항목 | 내용 |

| 경로 | 해석식 세 개. 나선 비행 *R* = 5 m, 주기 12 s, 상승 0.4 m/s. 8자 비행 *x* = 7 sin *ωt*, *y* = 3.2 + 1.4 cos *ωt*, *z* = 3.5 sin 2*ωt*, *ω* = 2π/16 s⁻¹. 등가속도 비행 *r⃗*₀ = (−8, 1, 1.6) m, *v⃗*₀ = (2, 3, −1.6) m/s, *a⃗* = (0, −0.75, 0.4) m/s². 화면용으로 정한 값이고 교재 값이 아니다 |

## 화살표 결정

**속도·가속도 화살표는 기본으로 보이고 체크 상자 "속도·가속도 화살표"로 끈다.** 2장과 4-2는 기본으로 끄거나 없앴지만 이 화면은 *v⃗*avg → *v⃗*, *a⃗*avg → *a⃗*처럼 벡터 자체가 학습 내용이라 화살표가 없으면 할 일이 없다. 체크 상자를 끄면 위치 벡터와 변위만 남아 학생이 평균 속도의 방향을 먼저 그려 보게 한다. 방향 예측 활동은 고르기 전에 *v⃗*와 *a⃗*를 그리지 않는다. 사용자가 다시 확인할 항목이다.
