# 7-2 변하는 힘이 하는 일

교재 Principles of Physics 12e, Chapter 7, Module 7.4 Work Done by a Spring Force와 Module 7.5 Work Done by a General Variable Force 화면이다. 힘이 위치에 따라 변하면 일은 *F*–*x* 그래프 아래 넓이다. 활동은 둘이고 둘 다 재생 전에 예측하고 채점한다.

| 활동 | 학생이 하는 일 | 교재 대응 |
|---|---|---|
| 용수철 | 용수철 상수 *k*, 처음 위치 *x*<sub>i</sub>, 나중 위치 *x*<sub>f</sub>를 정한다. 가한 힘이 블록을 천천히 옮기는 동안 용수철 힘이 한 일 *W*<sub>s</sub>와 가한 힘이 한 일 *W*<sub>a</sub>를 적는다 | Eq. (7.4.2), (7.4.6), (7.4.7), (7.4.9), Sample Problem 7.4.1의 배치, LO 7.4.1–7.4.5 |
| 그래프 넓이 | *x* = 0, 2, 4, 6 m의 힘을 정해 꺾은선 *F*(*x*)를 만든다. 0에서 6 m까지 일 *W*와 6 m에서 속력 *v*<sub>f</sub>를 적는다 | Eq. (7.5.8)의 넓이 풀이, (7.2.9), Sample Problem 7.5.1의 방법(넓이를 조각으로 나눠 더함), LO 7.5.1, 7.5.2, 7.5.4 |

## 모델

| 항목 | 내용 |
|---|---|
| 용수철 | *F*<sub>x</sub> = −*kx*(식 7.4.2), *W*<sub>s</sub> = ½*kx*<sub>i</sub>² − ½*kx*<sub>f</sub>²(식 7.4.6). 블록은 처음과 끝에 정지해 있으므로 *W*<sub>a</sub> = −*W*<sub>s</sub>(식 7.4.9). 3 s 동안 *x*<sub>i</sub>에서 *x*<sub>f</sub>까지 일정한 빠르기로 옮긴다 |
| 그래프 넓이 | 마디 사이를 직선으로 이은 *F*(*x*). 일은 사다리꼴 넓이의 합으로 정확히 낸다. *v*(*x*) = √(*v*<sub>i</sub>² + 2*W*(*x*)/*m*). 시각 *t*(*x*) = ∫d*x*/*v*(*x*)를 2000칸 Simpson 적분으로 표를 만들고 거꾸로 찾아 블록 위치를 낸다 |
| 가정 | 바닥에 마찰이 없다. 용수철은 질량이 없다. 그래프 활동의 힘은 0 이상(slider 0–12 N)이라 블록이 멈추거나 되돌아오지 않는다 |
| 채점 | 2% 또는 0.001 안이면 정답. 부호가 바뀐 *W*<sub>s</sub>, ½*k*(*x*<sub>f</sub> − *x*<sub>i</sub>)², ½을 빠뜨린 값, *W*<sub>a</sub> = *W*<sub>s</sub>, 기운 선 아래를 직사각형으로 센 넓이, 가장 큰 힘 × 6 m, *K*<sub>i</sub>를 빠뜨리거나 속력을 더한 *v*<sub>f</sub>를 따로 알려 준다 |
| 시험 | `model.test.js` 6개. Sample Problem 7.4.1(*k* = 408 N/m, *W*<sub>s</sub> = −0.059 J, +0.030 J), 용수철 일이 방향을 따진 넓이와 수치 적분에 맞는지, 그래프 넓이와 *K*<sub>f</sub> = *K*<sub>i</sub> + *W*, 일정한 힘일 때 위치가 *v*<sub>i</sub>*t* + ½(*F*/*m*)*t*²와 2 × 10⁻⁶ 안에서 같은지와 d*x*/d*t* = *v*(*x*), 채점, slider 전 범위 300조합 |

Sample Problem 값은 시험에만 쓰고 화면에는 쓰지 않는다. Sample Problem 7.5.1은 교재 그림의 그래프에서 넓이 열한 조각을 읽어 0.238 J을 더한다. 그림 값이 추출문에 없어 시험에 넣지 않았다. 영어 용어(spring force, spring constant, Hooke’s law, relaxed state, applied force, variable force)는 교재 `c07`에서 확인했다.
