# 9-2 충돌과 충격량

교재 Principles of Physics 12e, Chapter 9, Module 9.4 Collision and Impulse 화면이다. 벽에 부딪히는 공이 받는 힘 펄스의 *F*–*t* 넓이가 충격량이다. 그만큼 운동량이 바뀐다. 활동은 둘이고 둘 다 재생 전에 예측하고 채점한다.

| 활동 | 학생이 하는 일 | 교재 대응 |
|---|---|---|
| 힘 펄스 | 공 질량 *m*, 다가오는 속력 *v*, 펄스 모양(삼각형, 반 사인), 최대 힘 *F*<sub>max</sub>, 접촉 시간 Δ*t*를 정한다. 충격량 *J*와 나중 속도 *v*<sub>f</sub>를 적는다 | Eq. (9.4.3), (9.4.4), LO 9.4.1, 9.4.2, 9.4.5, 9.4.6 |
| 부드럽게 멈추기 | 벽에 멈추는 공의 접촉 시간 Δ*t*를 정한다. 충격량은 *mv*로 같고 평균 힘 *F*<sub>avg</sub>를 적는다 | Eq. (9.4.8), LO 9.4.3, 9.4.4 |

## 모델

| 항목 | 내용 |
|---|---|
| 힘 펄스 | 삼각형 *J* = ½*F*<sub>max</sub>Δ*t*, 반 사인 *J* = (2/π)*F*<sub>max</sub>Δ*t*. 접촉 중 *J*(*t*)는 닫힌 식이다. +*x*는 벽에서 멀어지는 쪽이라 *v*<sub>f</sub> = −*v* + *J*/*m* |
| 부드럽게 멈추기 | 삼각형 펄스의 넓이를 *mv*로 맞춘다(*F*<sub>max</sub> = 2*mv*/Δ*t*). *F*<sub>avg</sub> = *mv*/Δ*t* |
| 화면 시간 | 다가오기 0.4 s와 튀어 나가기 0.4 s는 실제 시간이다. 몇 ms인 접촉은 화면에서 2.4 s로 늘여 보인다. 측정값의 시간은 물리 시간(ms)이다 |
| 채점 | 2% 또는 0.01 안이면 정답. 직사각형 넓이, ms를 그대로 쓴 값, 반 사인을 삼각형으로 센 값, 처음 속도 부호를 빠뜨린 값, 방향만 틀린 값, 처음 운동량을 빠뜨린 값, 평균 힘 대신 최대 힘이나 충격량을 쓴 값을 따로 알려 준다 |
| 시험 | `model.test.js` 5개. Sample Problem 9.4.1(*J* = 9.444 kg·m/s, 같은 충격량의 11 ms 삼각형 펄스로 65 km/h → 20 km/h, 머리 1.848 m/s와 17.1*g*), 닫힌 식 *J*(*t*)와 Simpson 수치 적분의 일치, 접촉 중 매 순간 Δ*p* = *J*, 채점, slider 전 범위 300조합 |

Sample Problem 값은 시험에만 쓰고 화면에는 쓰지 않는다. Sample Problem 9.4.1의 머리 가속도는 교재에 167.8 m/s²로 적혀 있다. 1.848 m/s를 0.011 s로 그대로 나누면 168.0 m/s²라 시험은 0.2% 허용으로 대조했다. 두 값 모두 17.1*g*다. 영어 용어(impulse, collision, average force, linear momentum–impulse theorem)는 교재 `c09`에서 확인했다.
