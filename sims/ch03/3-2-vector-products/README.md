# 3-2 내적과 외적

교재 Principles of Physics 12e, Chapter 3, Module 3.3 Multiplying Vectors 화면이다. 활동은 셋이고 채점하는 활동이 둘이다.

| 활동 | 학생이 하는 일 | 교재 대응 |
|---|---|---|
| 내적 | *a⃗*, *b⃗*의 성분을 정하면 사이 각 *ϕ*, 한 벡터의 머리에서 다른 벡터 방향 직선으로 내린 수선, 그 방향 성분(*b* cos *ϕ* 또는 *a* cos *ϕ*)이 그려진다. 식 (3.3.1)과 (3.3.4)에 현재 값이 들어가 같은 스칼라 곱이 나온다. 오른쪽 판은 지금 *a*, *b*로 그린 *ab* cos *ϕ* 곡선과 지금 *ϕ*의 점(외적 활동은 *ab* sin *ϕ*)이다 | Eq. (3.3.1), (3.3.2), (3.3.4), LO 3.3.2–3.3.5 |
| 외적 | 같은 *a⃗*, *b⃗*가 이루는 평면과 *a⃗*에서 *b⃗*로 감는 호를 보고 ①–④ 가운데 *a⃗* × *b⃗*의 방향을 먼저 고른다. 확인하면 오른손이 *a⃗*에서 *b⃗*로 손가락을 감고 엄지를 따라 *c⃗*가 자란다. 순서 바꾼 곱 *b⃗* × *a⃗*를 켤 수 있다 | Eq. (3.3.5), (3.3.6), (3.3.8), LO 3.3.2, 3.3.6, 3.3.7 |
| 곱 계산 | 11문제. 단위 벡터끼리의 벡터 곱 방향(오른손 규칙), 성분으로 스칼라 곱과 *ϕ*, 성분으로 벡터 곱, 장면을 돌려 보고 스칼라 곱의 부호, 스칼라 곱하기 벡터의 방향과 크기를 구한다 | Eq. (3.3.1), (3.3.4), (3.3.5), (3.3.8), LO 3.3.1, 3.3.3, 3.3.4, 3.3.6, 3.3.7 |

LO 3.3.8(nested products)은 다루지 않는다.

## 모델

| 항목 | 내용 |
|---|---|
| 벡터 | 단위 없는 수다(Sample Problem 3.3.1, 3.3.3과 같다). 성분은 −3에서 3까지 0.5 간격 |
| 사이 각 | *ϕ* = atan2(\|*a⃗* × *b⃗*\|, *a⃗* · *b⃗*)로 0°–180°다. 식 (3.3.5)가 요구하는 작은 각이고 (3.3.1)에도 그대로 쓴다 |
| 벡터 곱 | 식 (3.3.8)의 항 순서 그대로 계산한다 |
| 방향 성분 | *b* cos *ϕ* = *a⃗* · *b⃗* / *a*. 수선의 발이 꼬리 뒤에 오면 직선을 점선으로 늘린다 |
| 오른손 규칙 후보 | ①과 ②는 평면의 두 법선, ③은 *a⃗*와 *b⃗* 사이의 평면 안 방향, ④는 *c⃗* = 0이다. ①은 위(+*y*)를 더 향하는 법선이라 정답 번호가 벡터에 따라 바뀐다. 평행이나 반평행이면 ④가 정답이다 |
| *c⃗* 길이 | 장면에서 1/2로 줄여 그렸다. 범례와 가정에 적었다 |
| 채점 | 값은 1% 또는 0.03 안, 각은 1° 안이면 정답이다. 반대 방향(순서 바꾼 곱), 평면 안 방향, 0 오답, cos *ϕ* 부호에서 나온 보각, 부호가 모두 반대인 성분, \|*s*\|배를 빼먹은 크기는 따로 알려 준다 |
| 시험 | `model.test.js` 10개 |

| Sample Problem | 교재 답 | 시험에서 확인한 값 |
|---|---|---|
| 3.3.1 | *a* = 5.00, *b* = 3.61, *a⃗* · *b⃗* = −6.0, *ϕ* = 109° ≈ 110° | 같은 값 |
| 3.3.2 | *c* = 216, *c⃗*는 xy 평면에서 +*x*로부터 160° | 같은 값 |
| 3.3.3 | *c⃗* = −12*î* − 9*ĵ* − 8*k̂* | 같은 값, *c⃗* · *a⃗* = *c⃗* · *b⃗* = 0 |

Sample Problem 값은 시험에만 쓰고 화면에는 쓰지 않는다. 화면의 문제 11개는 이 화면용으로 정한 수다. 식 번호와 값은 `c03.pdf` 51–56쪽에서 확인했다. *î* × *ĵ* = *k̂*와 *î* × *î* = 0은 교재 본문에 번호 없이 나와 화면에도 번호 없이 적었다.

## 색과 선 모양

| 대상 | 색 | 선 모양과 글자 |
|---|---|---|
| *a⃗* | #0072B2 | 굵은 실선 화살표, 머리 옆 KaTeX *a⃗* |
| *b⃗* | #D55E00 | 굵은 실선 화살표 |
| *c⃗* = *a⃗* × *b⃗* | #009E73 | 더 굵은 실선, 길이 1/2 |
| *c⃗*′ = *b⃗* × *a⃗* | #009E73 | 점선 화살표, 이름 *c⃗*′ |
| 방향 성분 | 투영한 벡터의 색 | 벡터 직선 옆에 나란한 반투명 막대와 값 태그 |
| *v⃗*와 *s v⃗* (스칼라 곱하기 벡터) | #0072B2와 #CC79A7 | 실선, 곱 계산의 한 문제에서만 |
| 단위 벡터 *î*, *ĵ*, *k̂* | #000000 | 길이 1, 측정대 왼쪽 앞 모서리 |
| 후보 ①–③ | #8D9AA7 | 가는 회색 화살표와 번호 |

색은 3-1과 같은 규칙이다. *a⃗*, *b⃗*, 곱의 결과는 특정 물리량이 아니어서 05 §색의 다섯 색 가운데 서로 다른 색을 골랐다. 모든 화살표 머리에는 이름을 달았다. *c⃗*′은 *c⃗*와 관계있는 양(−*c⃗*)이라 같은 색에 점선으로 갈랐다.
