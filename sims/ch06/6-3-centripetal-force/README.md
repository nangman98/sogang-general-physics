# 6-3 원운동의 구심력

교재 Principles of Physics 12e, Chapter 6, Module 6.3 Uniform Circular Motion 화면이다. 구심력은 새로운 종류의 힘이 아니라 중심을 향하는 알짜힘이라는 점을 마찰력, 기울어진 수직항력, 중력과 수직항력의 합으로 보여 준다. 활동은 셋이고 모두 재생 전에 예측하고 채점한다.

| 활동 | 학생이 하는 일 | 교재 대응 |
|---|---|---|
| 평평한 커브 | 속력 *v*, 커브 반지름 *R*, 정지 마찰 계수 *μ*<sub>s</sub>를 정한다. 최대 속력 *v*<sub>max</sub>와 지금 속력에서 필요한 마찰력을 적는다 | 6.3 본문 예 1(커브를 도는 차), Eq. (6.3.1), (6.3.2), (6.1.1), LO 6.3.2, 6.3.3 |
| 경사진 커브 | *R*과 경사각 *θ*를 정한다. 마찰 없이 도는 속력을 적고 수직항력과 *mg*를 비교한다 | Eq. (6.3.2), 6장 문제 44의 배치(banked curve), LO 6.3.1, 6.3.3 |
| 연직 원 | 고리 반지름 *R*, 꼭대기 속력 *v*, 질량 *m*을 정한다. 꼭대기의 최소 속력과 지금 속력에서 꼭대기의 수직항력을 적는다 | Eq. (6.3.3), Sample Problem 6.3.1의 배치, LO 6.3.3 |

## 모델

| 항목 | 내용 |
|---|---|
| 평평한 커브 | 마찰력이 구심력이다. *mv*²/*R* ≤ *μ*<sub>s</sub>*mg*이면 반지름 *R*로 돌고 *f* = *mv*²/*R*. 더 빠르면 최대 정지 마찰력으로 가장 작게 도는 원(반지름 *v*²/(*μ*<sub>s</sub>*g*), 출발점에서 도로에 접한다)을 따라 도로 밖으로 나간다. *v*<sub>max</sub> = √(*μ*<sub>s</sub>*gR*) |
| 경사진 커브 | 마찰 없음. *F*<sub>N</sub> cos *θ* = *mg*, *F*<sub>N</sub> sin *θ* = *mv*²/*R*에서 *v* = √(*gR* tan *θ*), *F*<sub>N</sub> = *mg*/cos *θ*. 차는 이 속력으로 돈다 |
| 연직 원 | 수레를 입자로 보고 꼭대기 근처를 속력 *v*의 등속 원운동으로 본다(교재 Sample Problem 6.3.1과 같다). 꼭대기에서 *φ*만큼 떨어진 곳의 수직항력은 *F*<sub>N</sub> = *mv*²/*R* − *mg* cos *φ*(*φ* = 0에서 식 6.3.3). *F*<sub>N</sub>이 0이 되는 곳에서 트랙을 떠나 포물선으로 떨어진다. 꼭대기 최소 속력 *v*<sub>min</sub> = √(*gR*) |
| 상수 | 자동차 질량 1000 kg, 도로 반폭 2.2 m, *g* = 9.8 m/s². 연직 원은 꼭대기 앞 55°에서 출발해 꼭대기 뒤 55°까지 간다 |
| 재생 | 닫힌 식으로 매 시각 값을 낸다. 커브를 따라 도는 차는 한 바퀴를 되풀이한다. 도로 밖으로 나가는 차는 도로 바깥 가장자리에서 3 m 지나 멈춘다. 떨어지는 수레는 고리 중심 높이에서 멈춘다. 재생 속도 1×로 시작한다 |
| 채점 | 속력과 힘은 2% 또는 0.01 안이면 정답. 따로 알려 주는 실수는 제곱근이나 *g*, *μ*<sub>s</sub>를 빠뜨린 *v*<sub>max</sub>, 필요한 마찰력 대신 최대 정지 마찰력이나 *mg*, *v*를 제곱하지 않은 값, 경사진 커브에서 tan 대신 sin을 쓰거나 뒤집은 값, 경사각을 빠뜨린 값, 꼭대기 수직항력에서 *mg*를 더하거나 빠뜨린 값, √(2*gR*), 최소 속력보다 느린데 0이 아닌 수직항력이다 |
| 시험 | `model.test.js` 7개. Sample Problem 6.3.1(*v* = 5.1 m/s, *F*<sub>N</sub> = 0, 식 6.3.3과 질량 무관), 6.3.2(*a* = 8.38 m/s², *F* = 662 N), 평평한 커브의 *v*<sub>max</sub>와 도로 밖 경로(접점에서 위치와 속도 일치), 경사진 커브의 두 식, 연직 원의 접촉 끝 각과 그 시각 위치 연속, 채점, slider 전 범위 1200조합 |

Sample Problem 값은 시험에만 쓰고 화면에는 쓰지 않는다. 교재 6.3 본문에는 경사진 커브의 풀이가 없고 6장 문제 44에 배치만 나온다. 그래서 경사진 커브는 두 식을 서로 대조하는 시험으로 확인했다. 영어 용어(uniform circular motion, centripetal force, centripetal acceleration, normal force, frictional force, banked curve)는 교재 `c06`에서 확인했다.
