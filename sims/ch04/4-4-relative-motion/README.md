# 4-4 강을 건너는 배의 상대 속도

교재 Principles of Physics 12e, Chapter 4, Module 4.7 Relative Motion in Two Dimensions (Learning Objective 4.7.1)와 Module 4.6 Relative Motion in One Dimension의 위치·속도 관계 화면이다. 배 P가 강을 건너는 동안 강가에 붙인 기준틀 A와 강물에 붙인 기준틀 B에서 같은 운동을 본다. 표기는 교재 그대로 *v⃗*PA = *v⃗*PB + *v⃗*BA (Eq. 4.7.2)다. 활동은 셋이다.

| 활동 | 학생이 하는 일 | 교재 대응 |
|---|---|---|
| 속도 더하기 | 강물에 대한 배의 속력, 강물의 속력, 뱃머리 각을 정하고 재생한다. 강가(frame A)에서 보면 *v⃗*PB 끝에 *v⃗*BA를 이어 붙인 *v⃗*PA로 가고 *r⃗*PA = *r⃗*PB + *r⃗*BA 세 위치 벡터가 삼각형을 이룬다. 강물(frame B)에서 보면 부표가 멈추고 배는 뱃머리 방향으로 곧게 가며 강가가 *v⃗*AB = −*v⃗*BA로 밀려간다 | Eq. (4.7.1), (4.7.2), Fig. 4.7.1의 내용, LO 4.7.1 |
| 도착 예측 | 재생 단추가 없는 상태에서 건너는 시간 *t*와 도착 지점 *x*를 적는다. 확인하면 회색 깃발이 예측 자리에 서고 재생 단추가 나온다. 문제 6개 | Eq. (4.7.2), *x* 성분은 Eq. (4.6.2)와 같은 꼴 |
| 방향 맞추기 | 바로 맞은편에 닿는 뱃머리 각 *θ*를 적거나 "어떤 각으로도 닿을 수 없다"를 고른다. 확인하면 적은 각으로 배가 출발한다. 문제 5개, 하나는 배가 강물보다 느려 닿을 수 없다 | SP 4.7.1과 같은 풀이(가로 성분을 0으로) |

## 모델

| 항목 | 내용 |
|---|---|
| 좌표 | *x*는 하류, *y*는 위, *z*는 가까운 강가 쪽. 출발점 O가 기준틀 A의 원점이고 *t* = 0에 B의 원점도 O에 있다. 건너편 도착선은 *z* = −*D*, *D* = 24 m |
| 식 | *v⃗*PB = *v*PB(−sin *θ*, 0, −cos *θ*), *v⃗*BA = (*v*BA, 0, 0), *v⃗*PA = *v⃗*PB + *v⃗*BA. 건너는 시간 *t* = *D*/(*v*PB cos *θ*), 도착 지점 *x* = (*v*BA − *v*PB sin *θ*)*t*. 적분기 없음 |
| 각 | *θ*는 바로 건너는 방향에서 상류 쪽이 +. 교재 SP 4.7.1의 *θ*(동쪽에서 남쪽으로 잰 각)와 정의가 다르다 |
| 범위 | *v*PB 2–6 m/s, *v*BA 0–3 m/s, *θ* −45°–60° |
| 도착 채점 | 시간 2%, 도착 지점 3% 또는 0.5 m 안이면 정답. *D*/*v*PB(cos *θ* 빠뜨림), *D*/\|*v⃗*PA\|(합속도로 나눔), 부호 반대, 뱃머리 몫이나 강물 몫을 빠뜨린 *x*를 따로 알려 준다 |
| 방향 채점 | *θ* = sin⁻¹(*v*BA/*v*PB)에서 1° 안이면 정답. 하류 쪽으로 돌린 답과 tan⁻¹(*v*BA/*v*PB)를 쓴 답을 따로 알려 준다 |
| 화살표 축척 | 속도 1 m/s당 1.5 m (`spec.js`의 `SCALE`) |
| 시험 | `model.test.js` 8개 |

## 화살표 결정

**속도 화살표는 기본으로 보이고 체크 상자 "속도 화살표"로 끈다.** 이 화면은 세 속도의 벡터 합이 학습 내용이라 화살표가 기본이다. 도착 예측은 확인 전에 *v⃗*PA를 그리지 않고 주어진 *v⃗*PB와 *v⃗*BA만 그린다. 사용자가 다시 확인할 항목이다.
