# 14-2 아르키메데스 원리

교재 Principles of Physics 12e, Chapter 14, Module 14.5 Archimedes' Principle 화면이다. 부력이 밀려난 액체의 무게와 같다는 원리로 뜨는 블록의 잠긴 깊이와 물에 담근 물체의 겉보기 무게를 구한다. 활동은 둘이고 둘 다 재생 전에 예측하고 채점한다.

| 활동 | 학생이 하는 일 | 교재 대응 |
|---|---|---|
| 뜨는 블록 | 액체, 블록 밀도 *ρ*, 한 변 *H*를 정한다. 떠 있을 때 잠기는 깊이 *h*와 완전히 잠긴 채 놓은 직후 가속도의 크기를 적는다 | Eq. (14.5.1)–(14.5.3), Sample Problem 14.5.2, LO 14.5.1–14.5.4 |
| 겉보기 무게 | 액체, 물체 재료, 부피 *V*를 정한다. 완전히 잠겼을 때 부력과 저울 눈금을 적는다 | Eq. (14.5.1), (14.5.4), Sample Problem 14.5.1의 부력 계산, LO 14.5.5–14.5.6 |

## 모델

| 항목 | 내용 |
|---|---|
| 뜨는 블록 | *h* = (*ρ*/*ρ*<sub>f</sub>)*H*, 놓은 직후 *a* = (*ρ*<sub>f</sub>/*ρ* − 1)*g*. 일부만 잠기면 *ρHa* = *ρ*<sub>f</sub>*sg* − *ρHg*가 잠긴 깊이 *s*에 비례하므로 블록은 *s* = *h*를 가운데로 *s* = *H*와 2*h* − *H* 사이를 흔들린다 |
| 범위 | 블록이 액체 밖으로 튀어나오지 않도록 *ρ*를 *ρ*<sub>f</sub>의 0.5–0.95배로 제한했다(2*h* − *H* ≥ 0) |
| 겉보기 무게 | *F*<sub>b</sub> = *ρ*<sub>f</sub>*V*<sub>sub</sub>*g*, 눈금 = *ρVg* − *F*<sub>b</sub>. 물체는 공기 중에서 내려가 잠기는 동안 언제나 평형이다 |
| 밀도 | 물 998, 바닷물 1024, 수은 13.6 × 10³, 철 7.9 × 10³ kg/m³(Table 14.1.1), 알루미늄 2710, 유리 2190, 콘크리트 2320 kg/m³(Table 12.3.1) |
| 가정 | 물의 끌림, 함께 움직이는 물의 질량, 수면 높이 변화는 무시한다. 재생은 실제보다 4배 느리다(`timeScale` 0.25) |
| 채점 | 2% 또는 0.01 안이면 정답. 수면 위 높이 *H* − *h*, 밀도 비를 거꾸로 쓴 깊이, 가속도 *g*와 (*ρ*<sub>f</sub>/*ρ*)*g*, 물체 밀도로 구한 부력, 단위 변환 실수, 실제 무게와 무게 + 부력을 따로 알려 준다 |
| 시험 | `model.test.js` 5개. Sample Problem 14.5.2(*h* = 4.0 cm, *a* = 4.9 m/s²), 14.5.1의 부력(2.509 × 10² N), 뜰 때 *F*<sub>b</sub> = *F*<sub>g</sub>와 흔들림의 운동 방정식(중앙 차분), 슬라이더 범위에서 블록이 액체 안에 머묾, 겉보기 무게와 내리는 동안의 눈금, 채점 |

Sample Problem 값은 시험에만 쓰고 화면에는 쓰지 않는다. 영어 용어(buoyant force, displaced fluid, apparent weight)는 교재 `c14`에서 확인했다.
