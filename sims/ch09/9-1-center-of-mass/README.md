# 9-1 질량중심

교재 Principles of Physics 12e, Chapter 9, Module 9.1 Center of Mass와 Module 9.2 Newton’s Second Law for a System of Particles 화면이다. 활동은 둘이고 둘 다 예측하고 채점한다.

| 활동 | 학생이 하는 일 | 교재 대응 |
|---|---|---|
| 질량중심 찾기 | 정삼각형 꼭짓점에 놓인 세 입자의 질량과 한 변 *a*를 정한다. 질량중심 좌표 *x*<sub>com</sub>, *y*<sub>com</sub>을 적는다 | Eq. (9.1.5), Sample Problem 9.1.1의 배치, LO 9.1.1–9.1.3 |
| 쪼개지는 포탄 | 발사 속력 *v*<sub>0</sub>, 발사 각 *θ*<sub>0</sub>, 조각 1의 질량 비율 *m*<sub>1</sub>/*M*을 정한다. 꼭대기에서 조각 1이 멈춰 곧장 떨어질 때 조각 2가 떨어지는 곳을 적는다 | Eq. (9.1.2), (9.2.1), LO 9.2.1, 9.2.2 |

## 모델

| 항목 | 내용 |
|---|---|
| 질량중심 찾기 | 입자 1 (0, 0), 입자 2 (*a*, 0), 입자 3 (*a*/2, √3*a*/2). *x*<sub>com</sub> = Σ*m*<sub>i</sub>*x*<sub>i</sub>/*M*, *y*<sub>com</sub> = Σ*m*<sub>i</sub>*y*<sub>i</sub>/*M*(식 9.1.5). 움직임이 없어 재생 단추를 숨긴다 |
| 쪼개지는 포탄 | 쪼개지기 전에는 포물선. 꼭대기에서 조각 1(질량 *m*<sub>1</sub>)은 속도가 0이 된다. 수평 운동량 보존으로 조각 2는 *v*<sub>x</sub> = (*M*/*m*<sub>2</sub>)*v*<sub>0</sub> cos *θ*<sub>0</sub>. 두 조각은 같은 높이에서 연직 속도 0으로 출발해 같이 떨어진다. 외력은 중력뿐이라 질량중심은 쪼개지지 않은 포물선을 따라 *R*에 떨어진다(식 9.2.1). 조각 2는 *x*<sub>2</sub> = (*MR* − *m*<sub>1</sub>*R*/2)/*m*<sub>2</sub> |
| 가정 | 공기 저항이 없다. 쪼개질 때의 힘은 내력이다. *g* = 9.8 m/s² |
| 채점 | 좌표는 2% 또는 0.01 m, 착지점은 2% 또는 0.05 m 안이면 정답. 질량을 곱하지 않은 평균, *M*으로 나누지 않은 값, 질량중심 착지점 *R*, 질량이 같을 때의 답 1.5*R*을 따로 알려 준다 |
| 시험 | `model.test.js` 5개. Sample Problem 9.1.1(*M* = 7.1 kg, (83 cm, 58 cm)), 같은 질량이면 무게중심 자리, 쪼개진 뒤의 수평 운동량 보존과 매 시각 질량중심이 원래 포물선 위에 있는지, 두 조각의 착지점, 채점, slider 전 범위 300조합 |

Sample Problem 값은 시험에만 쓰고 화면에는 쓰지 않는다. Sample Problem 9.2.1은 세 힘의 방향이 교재 그림에만 있어 추출문으로 확인할 수 없었다. 그래서 시험에 넣지 않았다. 영어 용어(center of mass, system of particles, external force, total mass)는 교재 `c09`에서 확인했다.
