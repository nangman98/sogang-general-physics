# 15-4 강제 진동과 공명

교재 Principles of Physics 12e, Chapter 15, Module 15.6 Forced Oscillations and Resonance 화면이다. 15.5의 감쇠 진동자(Fig. 15.5.1)를 지지대째 위아래로 흔든다. 학생은 공명이 일어나는 구동 각진동수와 그때의 변위 진폭을 확인 전에 구하고 채점받는다. 확인 뒤 구동 각진동수에 따른 진폭 곡선(공명 곡선)이 나타나고 *ω*<sub>d</sub> 슬라이더로 곡선 위를 옮겨 다닌다.

| 활동 | 학생이 하는 일 | 교재 대응 |
|---|---|---|
| 공명 곡선 | 질량 *m*, 용수철 상수 *k*, 감쇠 상수 *b*, 구동력 진폭 *F*<sub>m</sub>, 구동 각진동수 *ω*<sub>d</sub>를 정한다. 공명 구동 각진동수와 공명 변위 진폭을 적는다 | Eq. (15.6.1), (15.6.2), (15.5.1), (15.5.2), (15.1.12), Fig. 15.6.1, LO 15.6.1–15.6.3 |

## 모델

| 항목 | 내용 |
|---|---|
| 구동 | 15.6 본문처럼 지지대가 *y*<sub>s</sub> = *d* cos *ω*<sub>d</sub>*t*로 움직이면 용수철 힘이 *ky*<sub>s</sub>만큼 바뀐다. 이것이 구동력 *F*<sub>m</sub> cos *ω*<sub>d</sub>*t*이고 *F*<sub>m</sub> = *kd*다 |
| 운동 방정식 | 감쇠력 *F*<sub>d</sub> = −*bv*(Eq. 15.5.1)를 넣은 −*bv* − *kx* = *ma*(Eq. 15.5.2)에 구동력을 더해 *m* d²*x*/d*t*² + *b* d*x*/d*t* + *kx* = *F*<sub>m</sub> cos *ω*<sub>d</sub>*t* |
| 진폭과 위상 | 교재 본문에는 진폭 식이 없어서 식 (15.6.1) *x* = *x*<sub>m</sub> cos(*ω*<sub>d</sub>*t* + *ϕ*)를 위 방정식에 넣어 유도했다. *x*<sub>m</sub> = *F*<sub>m</sub>/√(*m*²(*ω*<sub>d</sub>² − *ω*²)² + *b*²*ω*<sub>d</sub>²), tan *ϕ* = −*bω*<sub>d</sub>/(*m*(*ω*² − *ω*<sub>d</sub>²)), −π < *ϕ* ≤ 0, *ω* = √(*k*/*m*)(Eq. 15.1.12). 진폭 식은 교재 15장 문제 34에 나오는 식과 같다. 위상은 장면을 움직이는 데만 쓴다 |
| 공명 | 속도 진폭 *v*<sub>m</sub> = *ω*<sub>d</sub>*x*<sub>m</sub>은 정확히 *ω*<sub>d</sub> = *ω*(Eq. 15.6.2)에서 가장 크고 그때 *x*<sub>m</sub> = *F*<sub>m</sub>/(*bω*), *ϕ* = −π/2다. 변위 진폭은 √(*ω*² − *b*²/2*m*²)에서 가장 크다. 기본값에서 이 값은 7.97 rad/s로 *ω*보다 0.39% 작다(교재의 "approximately") |
| 범위 | *m* 0.20–1.00 kg, *k* 10–50 N/m(*ω* 3.16–15.8 rad/s), *b* 0.20–2.00 kg/s, *F*<sub>m</sub> 0.10–1.00 N, *ω*<sub>d</sub> 1.0–20.0 rad/s. 봉우리 진폭은 0.333–158 cm다 |
| 가정 | 구동을 시작하고 충분히 지나 진폭이 일정해진 뒤의 운동(식 15.6.1)만 보인다. 교재 15.5처럼 블록의 중력은 무시한다. 재생은 구동 두 주기를 되풀이한다 |
| 채점 | 2% 또는 0.01 안이면 정답. *ω*<sub>d</sub>는 진동수 *ω*/2π, √(*m*/*k*), *k*/*m*을, *x*<sub>m</sub>은 아주 느리게 흔들 때의 진폭 *F*<sub>m</sub>/*k*, 속도 진폭 *F*<sub>m</sub>/*b*, m 단위 값을 따로 알려 준다. 기본값(*m* = 0.50 kg, *k* = 32 N/m, *b* = 0.50 kg/s, *F*<sub>m</sub> = 0.50 N)에서 답은 8.00 rad/s, 12.5 cm이고 실수 값(1.27, 0.125, 64.0 / 1.56, 1.00, 0.125)은 모두 2% 넘게 다르다. 답은 슬라이더의 *ω*<sub>d</sub>와 상관없다 |
| 시험 | `model.test.js` 6개. 중앙 차분으로 운동 방정식과 *v* = d*x*/d*t*, 지지대 힘 *ky*<sub>s</sub> = *F*<sub>m</sub> cos *ω*<sub>d</sub>*t*, 문제 34 식과 세 극한(*F*<sub>m</sub>/*k*, *F*<sub>m</sub>/*bω*, *F*<sub>m</sub>/*mω*<sub>d</sub>²), *v*<sub>m</sub>이 *ω*에서, *x*<sub>m</sub>이 √(*ω*² − *b*²/2*m*²)에서 최대(훑어 찾기), *b*와 2*b*의 봉우리 높이와 *v*<sub>m</sub>이 봉우리의 1/√2 이상인 폭 *b*/*m*(Fig. 15.6.1), 한 주기 평균 ⟨*Fv*⟩ = ⟨*bv*²⟩, 채점 |
