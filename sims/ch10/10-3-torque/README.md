# 10-3 돌림힘과 회전의 제2법칙

교재 Principles of Physics 12e, Chapter 10, Module 10.6 Torque와 Module 10.7 Newton’s Second Law for Rotation 화면이다. 힘이 물체를 돌리는 정도인 돌림힘을 힘의 방향과 작용점으로 본다. 이어서 돌림힘과 각가속도의 관계 *τ*<sub>net</sub> = *Iα*를 쓴다. 활동은 둘이고 둘 다 재생 전에 예측하고 채점한다.

| 활동 | 학생이 하는 일 | 교재 대응 |
|---|---|---|
| 돌림힘 | 원판의 질량·반지름, 힘의 크기 *F*, 힘이 작용하는 거리 *r*, 힘과 반지름 방향 사이 각 *φ*를 정한다. 돌림힘과 각가속도를 적는다 | Eq. (10.6.1)–(10.6.3), (10.7.4), LO 10.6.1–10.6.5, 10.7.1 |
| 도르래와 매단 블록 | 원판 도르래의 질량·반지름과 매단 블록 질량 *m*을 정한다. 블록의 가속도와 줄의 장력을 적는다 | Eq. (10.7.4), (10.3.6), LO 10.7.1 |

## 모델

| 항목 | 내용 |
|---|---|
| 돌림힘 | *τ* = *rF* sin *φ* = *r*<sub>⊥</sub>*F*, 고른 원판 *I* = ½*MR*², *α* = *τ*/*I*. 힘은 원판에 붙어 함께 돌므로 *τ*가 일정하고 3 s 동안 *ω* = *αt* |
| 도르래 | 블록 *mg* − *T* = *ma*, 원판 *TR* = *Iα*, 미끄러짐 없음 *a* = *αR*. 그래서 *a* = *mg*/(*m* + *M*/2), *T* = ½*Ma*, *α* = *a*/*R*. 블록이 2.2 m 내려가면 멈춘다 |
| 가정 | 축 마찰이 없다. 줄은 가볍고 늘어나지 않는다. *g* = 9.8 m/s² |
| 채점 | 2% 또는 0.001 안이면 정답. sin 대신 cos, sin을 빠뜨린 값, *r* 대신 *R*을 쓴 돌림힘, 고리의 *I*를 쓴 값, *τI*, 자유 낙하 *g*, 블록 무게와 같은 장력을 따로 알려 준다 |
| 시험 | `model.test.js` 6개. Sample Problem 10.7.2(유도 던지기 *F* = 300 N, 중력 돌림힘을 넣으면 613.6 N), 10.7.1(발의 돌림힘 합이 0일 때 *T* = 151 N, 17.74° 기울면 442 N), *τ* = *rF* sin *φ* = *rF*<sub>t</sub> = *r*<sub>⊥</sub>*F*, 도르래 세 식의 일치와 *M* → 0, *m* → 0 극한, 채점, slider 전 범위 300조합 |

교재 10.7의 Sample Problem은 발과 유도 던지기이고 도르래와 매단 블록은 10장 문제에만 나온다. 그래서 도르래 활동은 세 식의 일치와 극한으로 시험했다. Sample Problem 값은 시험에만 쓰고 화면에는 쓰지 않는다. 영어 용어(torque, moment arm, line of action, rotation axis, Newton’s second law for rotation)는 교재 `c10`에서 확인했다.
