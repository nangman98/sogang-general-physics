# 4-3 속도 벡터와 구심 가속도 벡터

교재 Principles of Physics 12e, Chapter 4, Module 4.5 Uniform Circular Motion (Learning Objectives 4.5.1–4.5.2) 화면이다. 자동차가 원형 트랙을 일정한 속력으로 돌 때 속도는 늘 접선 방향이고 구심 가속도는 늘 중심 방향이라 둘이 늘 수직임과 *a* = *v*²/*r*을 보인다. 활동은 셋이다.

| 활동 | 학생이 하는 일 | 교재 대응 |
|---|---|---|
| 벡터 보기 | *r*과 *v*를 정하고 재생한다. *v⃗*(파랑)와 *a⃗*(분홍)가 자동차 위에서 돌고 직각 표시가 따라간다. 측정값에 두 벡터 성분, 사이 각 90.0°, *v*, *a*, *T*가 나오고 식 (4.5.1), (4.5.2)에 현재 값이 들어간다. 재생은 두 바퀴를 한 주기로 일시정지할 때까지 되풀이한다 | Eq. (4.5.1), (4.5.2), Fig. 4.5.1의 내용, LO 4.5.1 |
| 방향 예측 | 트랙 위 한 점에서 회색 화살표 넷(앞, 뒤, 중심 쪽, 바깥쪽) 가운데 *v⃗*를 고르고 확인한 뒤 *a⃗*를 고른다. 문제 6개에 시계 방향과 시계 반대 방향이 섞여 있어 *v⃗*는 도는 방향을 따르고 *a⃗*는 늘 중심을 향함을 구분한다 | LO 4.5.1 |
| 크기 예측 | 값 문제(*a* 또는 *T*를 숫자로)와 배수 문제(*v* 두 배, *r* 두 배, 같은 *T*에서 *r* 두 배일 때 *a*는 몇 배)를 푼다. 확인하면 장면이 그 조건으로 달리고 측정값이 열린다 | Eq. (4.5.1), (4.5.2), LO 4.5.2 |

## 모델

| 항목 | 내용 |
|---|---|
| 식 | 위치 *r*(cos *φ*, 0, −sin *φ*), *φ* = (*v*/*r*)*t*. 속도와 가속도는 교재 Eq. (4.5.3), (4.5.6)을 교재 *y* → 장면 −*z*로 옮긴 꼴이다. 적분기 없음 |
| 좌표 | 교재 Fig. 4.5.2의 *xy* 평면이 장면의 수평면이다. 교재 *x*는 장면 *x*, 교재 *y*는 장면 −*z*라서 위에서 본 시계 반대 방향이 교재의 시계 반대 방향과 같다 |
| 범위 | *r* 10–40 m, *v* 4–14 m/s. *a*는 0.4–19.6 m/s² |
| 화살표 축척 | 속도 1 m/s당 0.5 m, 가속도 1 m/s²당 0.5 m (`spec.js`의 `SCALE`). 가장 큰 *a*에서도 화살표가 중심을 넘지 않는다 |
| 방향 채점 | 정답은 속도 앞쪽 접선, 가속도 중심 쪽. 오답마다 그 방향이 무엇인지 알려 준다. 속도와 가속도 문제의 정답 번호는 서로 다르다 |
| 크기 채점 | 값은 2% 안이면 정답. *a* = *v*/*r*로 제곱을 빠뜨린 답, 배수에서 *v*에 비례한다고 본 답(4배 대신 2배), 반대로 본 답(½ 대신 2)을 따로 알려 준다 |
| 시험 | `model.test.js` 8개 |

시험에 넣은 교재 값은 아래와 같다. Sample Problem 값은 시험에만 쓰고 화면에는 쓰지 않는다.

| 교재 | 확인한 값 |
|---|---|
| Sample Problem 4.5.1 | *v* = 640.31 m/s, 반 바퀴 24.0 s라 *T* = 48.0 s, *a* = 2π*v*/*T* = 83.81 m/s² ≈ 8.6*g* |
| Sample Problem 4.5.2 | *a* = *g* = 9.20 m/s², *r* = 6.37 × 10⁶ m + 200 km에서 *v* = 7770 m/s = 7.77 km/s, *T* = 1.47 h |

SP 4.5.1의 2π(640.31 m/s)/(48.0 s)는 83.817 m/s²다. 교재는 83.81로 적으므로 시험은 교재가 적은 마지막 자리(0.01 m/s²) 안에서 맞춘다. 8.6*g*는 *g* = 9.8 m/s²로 확인한다.

## 화살표 결정

**속도·가속도 화살표는 기본으로 보이고 체크 상자 "속도·가속도 화살표"로 끈다.** 4.4(4-2)는 사용자 결정으로 공에 화살표를 두지 않았지만 4.5는 두 벡터의 방향 관계가 학습 내용이라 화살표가 기본이다. 체크 상자를 끄면 학생이 먼저 방향을 말해 보고 켜서 확인한다. 방향 예측 활동은 고르기 전에 *v⃗*와 *a⃗*를 그리지 않는다. 사용자가 다시 확인할 항목이다.

Still open: 휴대폰 폭 390 px 캡처는 하지 않았다. *r* = 40 m에서는 자동차가 작게 보여 확대가 필요하다. 가속도를 만드는 힘(마찰)은 6장 내용이라 다루지 않았다. 범위 끝(*r* = 10 m, *v* = 14 m/s, 2*g*)이 실제 타이어로 가능한지는 이 화면에서 따지지 않는다.
