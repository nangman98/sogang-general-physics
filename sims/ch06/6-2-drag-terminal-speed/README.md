# 6-2 항력과 종단 속력

교재 Principles of Physics 12e, Chapter 6, Module 6.2 The Drag Force and Terminal Speed 화면이다. 공기 속에서 정지 상태로 떨어지기 시작한 공의 속력이 종단 속력에 다가가는 것을 본다. 활동은 둘이고 둘 다 재생 전에 예측하고 채점한다.

| 활동 | 학생이 하는 일 | 교재 대응 |
|---|---|---|
| 낙하 | 공의 질량 *m*, 반지름 *r*, 항력 계수 *C*를 정한다. 종단 속력 *v*<sub>t</sub>를 적고 종단 속력에 이른 뒤의 가속도를 고른다 | Eq. (6.2.1)–(6.2.3), Fig. 6.2.2, LO 6.2.1, 6.2.2 |
| 두 물체 비교 | 물체 2의 질량 배율 *m*<sub>2</sub>/*m*<sub>1</sub>과 넓이 배율 *A*<sub>2</sub>/*A*<sub>1</sub>을 정하고 *v*<sub>t2</sub>/*v*<sub>t1</sub>을 적는다. 넓이 배율 2, 질량 배율 1이 Sample Problem 6.2.1의 상황이다 | Eq. (6.2.3), Sample Problem 6.2.1, LO 6.2.2 |

## 모델

| 항목 | 내용 |
|---|---|
| 운동 방정식 | +*y*를 위쪽으로 잡으면 *D* − *F*<sub>g</sub> = *ma*(식 6.2.2), *D* = ½*CρAv*²(식 6.2.1), *F*<sub>g</sub> = *mg* |
| 닫힌 해 | 정지에서 출발하면 *v* = *v*<sub>t</sub> tanh(*gt*/*v*<sub>t</sub>), 떨어진 거리 *s* = (*v*<sub>t</sub>²/*g*) ln cosh(*gt*/*v*<sub>t</sub>), *a* = −*g* sech²(*gt*/*v*<sub>t</sub>). *v*<sub>t</sub> = √(2*F*<sub>g</sub>/(*CρA*))(식 6.2.3). 적분기를 쓰지 않는다 |
| 상수 | *ρ* = 1.21 kg/m³(20 °C, 1 atm 공기, 교재 Table 14.1.1), *g* = 9.8 m/s², *A* = π*r*² |
| 가정 | 둔한 물체(blunt body)이고 *C*는 속력과 상관없다(교재 6.2 본문). *C*의 slider 범위 0.4–1.0은 교재가 적은 일반적인 값의 범위다 |
| 재생 | 빠른 물체의 3*v*<sub>t</sub>/*g*까지 재생한다(*v*가 *v*<sub>t</sub>의 99.5%). 기본값(*m* = 0.15 kg, *r* = 4.0 cm, *C* = 0.50)에서 *v*<sub>t</sub> = 31.1 m/s, 재생 9.5 s, 떨어진 거리 228 m다 |
| 채점 | *v*<sub>t</sub>와 비는 2% 또는 0.01 안이면 정답. ½을 빠뜨린 값(*v*<sub>t</sub>/√2), 제곱근을 빠뜨린 값, 반지름을 cm로 넣은 값, 넓이를 π 없이 쓴 값, 비를 제곱근 없이 쓰거나 뒤집은 값, 질량·넓이 배율 중 하나만 쓴 값을 따로 알려 준다. 종단 속력에서 가속도는 0만 정답이다 |
| 시험 | `model.test.js` 6개. 식 6.2.1과 6.2.3의 일치(*v* = *v*<sub>t</sub>에서 *D* = *F*<sub>g</sub>), 닫힌 해가 식 6.2.2와 d*s*/d*t* = *v*를 만족하는지(중앙 차분), Table 6.2.1의 95% 거리 5개(2500, 430, 210, 115, 10 m)가 닫힌 해에서 나오는지, Sample Problem 6.2.1(97 km/h → 69 km/h), 채점, slider 전 범위 400조합 |

Sample Problem과 Table 6.2.1의 값은 시험에만 쓰고 화면에는 쓰지 않는다. Table 6.2.1의 테니스공(31 m/s)은 닫힌 해로 114 m가 나와 표의 115 m와 1 m 다르다. 시험은 114 m로 두었다. 영어 용어(drag force, terminal speed, drag coefficient, effective cross-sectional area, air density, gravitational force)는 교재 `c06`에서 확인했다.
