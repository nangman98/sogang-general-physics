## 모델

| 항목 | 내용 |
|---|---|
| 가열 곡선 | LO 18.4.9의 단계대로 얼음을 0 °C까지 데우고(*c*<sub>ice</sub>*m*Δ*T*, 식 18.4.3) 녹인 뒤(*L*<sub>F</sub>*m*, 식 18.4.5) 물을 데운다. 끓이기를 고르면 100 °C에서 모두 끓인다(*L*<sub>V</sub>*m*). 공급한 열 *Q*에서 온도와 얼음·물·수증기 질량을 닫힌 식으로 낸다 |
| 열평형 | 고체와 물만 열을 주고받는 고립계다. *c*<sub>s</sub>*m*<sub>s</sub>(*T*<sub>f</sub> − *T*<sub>s</sub>) + *c*<sub>w</sub>*m*<sub>w</sub>(*T*<sub>f</sub> − *T*<sub>w</sub>) = 0은 식 18.4.11에서 비커 항을 뺀 꼴이다. 재생은 옮겨 간 열을 0에서 *c*<sub>w</sub>*m*<sub>w</sub>(*T*<sub>f</sub> − *T*<sub>w</sub>)까지 바꾸며 두 온도를 식 18.4.3으로 낸다 |
| 값 | 비열(J/kg·K)은 Table 18.4.1의 얼음(−10 °C) 2220, 물 4187, 납 128, 텅스텐 134, 은 236, 구리 386, 알루미늄 900, 황동 380, 화강암 790, 유리 840이다. *L*<sub>F</sub> = 333 kJ/kg, *L*<sub>V</sub> = 2256 kJ/kg, 녹는점 273 K, 끓는점 373 K는 Table 18.4.2 값이다 |
| 범위 | 얼음 50–500 g, −40 °C에서 −2 °C, 물의 나중 온도 2–99 °C. 고체 50–300 g, 50–250 °C, 물 200–600 g, 5–40 °C. 이 범위의 끝값 조합 128가지에서 *T*<sub>f</sub>는 100 °C보다 낮다 |
| 가정 | 얼음 비열은 −10 °C 값을 −40 °C부터 0 °C까지 쓴다. 비커, 컵, 공기로 가는 열은 무시한다. 재생은 열의 진행을 보여 주고 실제 시간이 아니라서 시간 막대를 숨겼다 |
| 채점 | 2% 또는 0.01 안이면 정답. *Q*는 숨은열을 뺀 값, 기화열만 뺀 값, 얼음 데우기를 뺀 값, 얼음에 물의 비열을 쓴 값, *L*<sub>F</sub> 대신 *L*<sub>V</sub>를 쓴 값, J로 적은 값을 따로 알려 준다. *T*<sub>f</sub>는 두 온도의 평균, 질량만 넣은 평균, 비열만 넣은 평균, 두 비열을 바꾼 값, K로 적은 값을 따로 알려 준다. 물이 얻은 열은 부호를 바꾼 값, 고체가 물의 처음 온도까지 식었다고 본 값, J로 적은 값을 따로 알려 준다 |
| 시험 | `model.test.js` 5개. Sample Problem 18.4.1과 18.4.2, 가열 곡선의 기울기 1/(*cm*)와 0 °C·100 °C 수평 구간과 질량 보존, 열평형의 *Q*<sub>s</sub> + *Q*<sub>w</sub> = 0과 범위 끝값, 채점과 기본값에서 실수 값이 정답과 2% 넘게 다름 |

Sample Problem 18.4.1은 비커의 열용량 45 cal/K까지 넣어 cal 단위로 19.6 °C를 확인한다. 교재의 *Q*<sub>w</sub> ≈ 1670 cal, *Q*<sub>b</sub> ≈ 342 cal, *Q*<sub>c</sub> ≈ −2020 cal은 *T*<sub>f</sub>를 19.6 °C로 반올림해 얻은 값이라(반올림하지 않으면 1680, 344, −2024 cal) 시험도 반올림한 *T*<sub>f</sub>로 비교한다. Sample Problem 18.4.2는 물의 비열로 식 18.4.4의 4186.8 J/kg·K를 써서 45.22 kJ를 얻는다. 화면은 Table 18.4.1의 4187을 쓰고 시험은 4186.8로 교재 값을 재현한다. 세 단계의 합은 300.96 kJ이고 교재는 약 300 kJ로 적었다. (b)에서 녹은 질량은 0.583 kg이고 남은 얼음 137 g을 교재는 140 g으로 적었다. Sample Problem 값은 화면 기본값으로 쓰지 않는다. 영어 용어(heat, specific heat, heat of fusion, heat of vaporization, melting, vaporizing, phase change, thermal equilibrium, isolated system)는 교재 `c18`에서 확인했다. "가열 곡선"은 교재에 대응하는 영어 용어가 없어 한국어만 쓴다.
