# 12-1 벽에 기댄 사다리

교재 Principles of Physics 12e, Chapter 12, Module 12.2 Some Examples of Static Equilibrium 화면이다. 마찰 없는 벽에 기댄 사다리에 힘의 평형과 돌림힘의 평형을 적용한다. 활동은 둘이고 둘 다 확인 전에 예측하고 채점한다.

| 활동 | 학생이 하는 일 | 교재 대응 |
|---|---|---|
| 벽과 바닥의 힘 | 사다리 길이 *L*, 각 *θ*, 사다리 질량 *m*, 사람 질량 *M*, 사다리를 따라 사람의 위치 *d*를 정한다. 벽의 힘 *F*<sub>w</sub>와 바닥의 수직항력 *F*<sub>py</sub>를 적는다 | Eq. (12.1.7)–(12.1.9), (12.2.4)의 꼴, Sample Problem 12.2.3, LO 12.2.1–12.2.2 |
| 어디까지 오를까 | 바닥의 정지 마찰 계수 *μ*<sub>s</sub>를 정한다. 미끄러지기 전까지 오를 수 있는 거리 *d*를 적는다 | Eq. (6.1.1), (12.1.7)–(12.1.9) |

## 모델

| 항목 | 내용 |
|---|---|
| 돌림힘 평형 | 축을 아래 끝 O에 두면 −*hF*<sub>w</sub> + (*d* cos *θ*)*Mg* + (½*L* cos *θ*)*mg* = 0, *h* = *L* sin *θ* |
| 힘의 평형 | *F*<sub>px</sub> = *F*<sub>w</sub>(바닥의 정지 마찰력), *F*<sub>py</sub> = (*M* + *m*)*g* |
| 오를 수 있는 거리 | *F*<sub>w</sub>(*d*) = *μ*<sub>s</sub>(*M* + *m*)*g*인 *d*를 0과 *L* 사이로 자른다. 사람은 0.6 m/s로 오르고 그 점에서 멈춘다. 미끄러지는 운동은 그리지 않는다 |
| 가정 | 벽은 마찰이 없다. 사다리는 고르다. 사람의 무게는 사다리를 따라 *d*인 점의 연직선 위에 작용한다. *g* = 9.8 m/s² |
| 채점 | 2% 또는 0.01 안이면 정답. 돌림힘 팔의 sin과 cos을 바꾼 값, 사다리 무게를 뺀 값, 수직항력에 한쪽 무게만 넣은 값, 오를 거리에서 사다리 무게나 사다리의 수직항력 몫을 뺀 값을 따로 알려 준다 |
| 시험 | `model.test.js` 4개. Sample Problem 12.2.3(*a* = 7.58 m, *F*<sub>w</sub> = 407 N, *F*<sub>py</sub> = 1146.6 N, 질량중심 *L*/3), O와 위 끝 두 축에 대한 돌림힘 평형, 오를 거리에서 필요한 마찰력 = *μ*<sub>s</sub>*F*<sub>py</sub>와 멈춤, 채점 |

Sample Problem 12.2.3은 *F*<sub>w</sub>를 *a* = 7.58 m로 반올림해 407 N을 얻는다. 반올림하지 않으면 407.55 N이라 시험은 ±1 N으로 비교한다. Sample Problem 값은 시험에만 쓰고 화면에는 쓰지 않는다. 영어 용어(static equilibrium, balance of forces, balance of torques, moment arm, line of action)는 교재 `c12`에서 확인했다.
