# 2-2 등가속도 운동

교재 Principles of Physics 12e, Chapter 2, Module 2.4 Constant Acceleration (Learning Objective 2.4.1) 화면이다. 활동은 셋이다.

| 활동 | 학생이 하는 일 | 교재 대응 |
|---|---|---|
| 그래프 연동 | *x*₀, *v*₀, *a*를 정하고 재생하면 자동차와 *x*–*t*, *v*–*t*, *a*–*t* 판 세 장이 같은 시각 표시로 함께 움직인다. 식 (2.4.1), (2.4.5), (2.4.6)에 현재 값이 들어간다 | Eq. (2.4.1)–(2.4.6) |
| 빠진 양 | 알려진 양 셋과 구할 양 하나를 보고 Table 2.4.1의 식을 고른 뒤 값을 넣는다. 틀린 식과 부호 실수는 따로 알려 준다 | Table 2.4.1, LO 2.4.1 |
| 두 자동차 | 처음 만나는 시각을 먼저 적고 확인한다. *x*–*t* 판에 만나는 점이 표시된다 | Eq. (2.4.5) |

## 모델

| 항목 | 내용 |
|---|---|
| 식 | 매 시각 정확한 해 *x* = *x*₀ + *v*₀*t* + ½*at*², *v* = *v*₀ + *at*. 적분기 없음 |
| 시간 범위 | 0–10 s |
| slider 범위 | *x*₀ −50–50 m, *v*₀ −30–30 m/s, *a* −10–10 m/s². 자동차 B도 같다 |
| 만나는 시각 | (*x*₀,B − *x*₀) + (*v*₀,B − *v*₀)*t* + ½(*a*B − *a*)*t*² = 0의 (0, 10 s] 근. 근의 공식은 소거 오차가 작은 꼴을 쓴다 |
| 만남 채점 | 처음 만나는 시각과 0.05 s 또는 1% 안이면 정답. 두 번째 만남 시각은 따로 알려 준다 |
| 빠진 양 문제 | 8개 고정 목록, *x*₀ = 0. Table 2.4.1 다섯 식이 모두 한 번 이상 나온다. 근이 둘인 2차식으로 풀어야 하는 문제는 넣지 않았다 |
| 빠진 양 채점 | 고른 식의 빠진 양이 문제의 빠진 양과 같으면 식 정답, 값은 1% 안이면 정답. 부호만 반대면 부호 실수로 알려 준다 |
| 시험 | `model.test.js` 11개(Table 2.4.1 다섯 식의 일치, Sample Problem 2.4.1·2.4.2·2.4.3의 답, 위치 범위, 만나는 시각 4경우, 만남 채점, 빠진 양 문제와 채점, 되돌아가는 순간) |

Sample Problem 값은 시험에만 쓰고 화면에는 쓰지 않는다. 영어 용어(initial position, initial velocity, displacement, Missing Quantity)는 교재 `c02`에서 확인했다.
