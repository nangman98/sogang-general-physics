# 18-1 선팽창과 부피 팽창

교재 Principles of Physics 12e, Chapter 18, Module 18.3 Thermal Expansion 화면이다. 온도가 바뀔 때 막대의 길이, 판에 뚫린 구멍의 지름, 정육면체의 넓이와 부피가 얼마나 바뀌는지 예측한다. 활동은 둘이고 둘 다 재생 전에 예측하고 채점한다.

| 활동 | 학생이 하는 일 | 교재 대응 |
|---|---|---|
| 막대와 구멍 | 재료(Table 18.3.1), 막대 길이 *L*, 처음 온도 *T*<sub>i</sub>, 나중 온도 *T*<sub>f</sub>를 정한다. 길이 변화 Δ*L*을 적고 같은 재료 판에 뚫린 구멍의 지름이 커지는지, 그대로인지, 작아지는지 고른다 | Eq. (18.3.1), Fig. 18.3.3, Sample Problem 18.3.1, LO 18.3.1–18.3.2 |
| 정육면체 | 재료, 한 변 *a*, 두 온도를 정한다. 한 면의 넓이 변화 Δ*A*와 부피 변화 Δ*V*를 적는다 | Eq. (18.3.1)–(18.3.3), Sample Problem 18.3.2, LO 18.3.2–18.3.3 |

## 모델

| 항목 | 내용 |
|---|---|
| 선팽창 | Δ*L* = *Lα*Δ*T*(식 18.3.1). 판의 모든 길이가 같은 비율로 바뀌므로 지름 25 cm인 구멍도 Δ*D* = *Dα*Δ*T*를 따른다(Fig. 18.3.3) |
| 넓이와 부피 | 두 변이 식 18.3.1로 늘어나므로 (*α*Δ*T*)² 항을 버리면 Δ*A* = *A*(2*α*)Δ*T*(LO 18.3.2). Δ*V* = *Vβ*Δ*T*, *β* = 3*α*(식 18.3.2, 18.3.3). 슬라이더 범위 전체에서 정확한 (1 + *α*Δ*T*)³ − 1과의 차이가 0.64% 이하다 |
| 계수 | Table 18.3.1의 *α*(10⁻⁶/C°)는 납 29, 알루미늄 23, 황동 19, 구리 17, 콘크리트 12, 강철 11, 보통 유리 9, 파이렉스 유리 3.2, 다이아몬드 1.2, 인바 0.7, 용융 석영 0.5다. 얼음은 0°C에서만 맞는 값이라 뺐다 |
| 범위 | *L* 0.5–3.0 m, *a* 2–20 cm, *T*<sub>i</sub> −20–40 °C, *T*<sub>f</sub> −40–200 °C. 식히면 Δ*T*가 음수다. *α*는 상온 값을 이 범위에서 일정하게 쓴다 |
| 재생 | 온도를 *T*<sub>i</sub>에서 *T*<sub>f</sub>까지 2.5 s 동안 고르게 바꾼다. 실제 가열 시간이 아니므로 시간 막대를 숨겼다 |
| 채점 | 2% 또는 0.01 안이면 정답. Δ*L*은 부호를 바꾼 값, 3*α*를 쓴 값, Δ*T* 대신 *T*<sub>f</sub>를 곱한 값, 10배·1/10배·1/1000배 단위 실수를 따로 알려 준다. Δ*A*는 *α*나 3*α*를 쓴 값과 cm² 값, Δ*V*는 *α*나 2*α*를 쓴 값과 mm³ 값을 따로 알려 준다. 구멍은 데우면 "커진다", 식히면 "작아진다"가 정답이다 |
| 시험 | `model.test.js` 5개. Sample Problem 18.3.1과 18.3.2, 식 18.3.1–18.3.3과 정확한 팽창의 차이, 재생 중 Δ*L*, 채점과 기본값에서 실수 값이 정답과 2% 넘게 다름 |

Sample Problem 18.3.1의 *α* = 2.3 × 10⁻⁵/C°는 Table 18.3.1의 알루미늄 값과 같아 시험은 화면의 알루미늄으로 8.3 mm를 확인한다. Sample Problem 18.3.2는 37 000 − 808 = 36 192 L를 네 자리로 반올림해 36 190 L로 적었고 시험도 10 L 단위로 비교한다. 디젤 연료의 *β*는 Sample Problem에만 있어 시험에만 쓴다. Sample Problem 값은 화면 기본값으로 쓰지 않는다. 영어 용어(thermal expansion, coefficient of linear expansion, coefficient of volume expansion, length change, volume change)는 교재 `c18`에서 확인했다.
