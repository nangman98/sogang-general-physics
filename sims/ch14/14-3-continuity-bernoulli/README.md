# 14-3 연속 방정식과 베르누이 식

교재 Principles of Physics 12e, Chapter 14, Module 14.6 The Equation of Continuity, 14.7 Bernoulli's Equation 화면이다. 넓은 관에서 좁아지며 올라가는 관으로 물이 흐를 때 좁은 관의 속력과 압력을 재생 전에 구하고 채점한다.

| 활동 | 학생이 하는 일 | 교재 대응 |
|---|---|---|
| 좁아지며 올라가는 관 | 두 관의 넓이 *A*<sub>1</sub>, *A*<sub>2</sub>, 넓은 관의 속력 *v*<sub>1</sub>과 계기 압력 *p*<sub>1</sub>, 높이 차 Δ*y*를 정한다. 좁은 관의 속력 *v*<sub>2</sub>와 계기 압력 *p*<sub>2</sub>를 적는다 | Eq. (14.6.3), (14.6.4), (14.7.2), Sample Problem 14.6.1, 14.7.1, LO 14.6.1–14.6.4, 14.7.1–14.7.5 |

## 모델

| 항목 | 내용 |
|---|---|
| 연속과 베르누이 | *R*<sub>V</sub> = *A*<sub>1</sub>*v*<sub>1</sub> = *A*<sub>2</sub>*v*<sub>2</sub>, *p* + ½*ρv*² + *ρgy* = 일정. 관 위 모든 점의 속력과 압력을 이 두 식으로 구한다 |
| 관 모양 | 넓은 관 3 m(높이 0), 반지름과 높이가 고르게 바뀌는 구간 2 m, 좁은 관 3 m(높이 Δ*y*) |
| 표지 입자 | 36개가 관 중심선을 따라 국소 속력 *R*<sub>V</sub>/*A*로 움직인다. 들어간 뒤 지난 시간을 800칸 적분표로 만들고 보간으로 위치를 구한다. 한 번 흘러 지나가는 시간마다 되풀이한다 |
| 범위 | *A*<sub>2</sub>는 *A*<sub>1</sub>/4 이상 *A*<sub>1</sub> 이하. 계기 압력은 음수가 될 수 있고 절대 압력은 범위 안에서 양수다 |
| 가정 | 이상 유체(물, *ρ* = 998 kg/m³), 정상류, *g* = 9.8 m/s² |
| 채점 | 2% 또는 0.01 안이면 정답. 넓이 비를 거꾸로 쓴 속력, 그대로인 속력, 높이 항을 뺀 압력, 부호가 반대인 압력 변화, 그대로인 압력을 따로 알려 준다 |
| 시험 | `model.test.js` 5개. Sample Problem 14.7.1의 관계 *R*<sub>V</sub> = *A*<sub>1</sub>√(2Δ*p*/3*ρ*)(교재 값 2.24 × 10⁻³ m³/s), 14.6.1(28.6 cm/s, 34 cm³/s), 관 위 모든 점의 베르누이 값과 *R*<sub>V</sub> 일치, 표지 입자의 이동 시간과 국소 속력, 채점 |

Sample Problem 값은 시험에만 쓰고 화면에는 쓰지 않는다. 14.7.1은 에탄올(ρ = 791 kg/m³)이라 같은 관계식을 물로 시험한다. 영어 용어(ideal fluid, streamline, equation of continuity, volume flow rate, Bernoulli's equation)는 교재 `c14`에서 확인했다.
