# 9-4 2차원 충돌

교재 Principles of Physics 12e, Chapter 9, Module 9.8 Collisions in Two Dimensions 화면이다. 공기 테이블을 위에서 내려다보며 두 방향 모두에서 운동량이 보존되는 것을 운동량 그림으로 본다. 활동은 둘이고 둘 다 재생 전에 예측하고 채점한다.

| 활동 | 학생이 하는 일 | 교재 대응 |
|---|---|---|
| 비켜 맞는 탄성 충돌 | 두 퍽의 질량, 퍽 1의 속력, 비켜 맞는 거리 *b*를 정한다. 퍽 2가 나가는 방향 *θ*<sub>2</sub>와 속력 *v*<sub>2f</sub>를 적는다 | Eq. (9.8.1)–(9.8.5), LO 9.8.1 |
| 붙는 충돌 | +*x*로 오는 A와 +*y*로 오는 B의 질량과 속력을 정한다. 붙은 뒤 방향 *θ*와 속력 *V*를 적는다 | Eq. (9.8.6), (9.8.7), Sample Problem 9.8.1의 배치, LO 9.8.1 |

## 모델

| 항목 | 내용 |
|---|---|
| 비켜 맞는 탄성 충돌 | 반지름 *r* = 0.25 m의 매끄러운 퍽. 미는 힘은 맞닿은 두 중심을 잇는 방향 **n**을 따른다. 퍽 2는 **n** 방향, *θ*<sub>2</sub> = sin⁻¹(*b*/2*r*)로 나가고 *v*<sub>2f</sub> = 2*m*<sub>1</sub>/(*m*<sub>1</sub> + *m*<sub>2</sub>)·*v*<sub>1i</sub> cos *θ*<sub>2</sub>. 퍽 1은 **v**<sub>1f</sub> = **v**<sub>1i</sub> − 2*m*<sub>2</sub>/(*m*<sub>1</sub> + *m*<sub>2</sub>)(**v**<sub>1i</sub>·**n**)**n**. 질량이 같으면 두 방향이 90° 벌어진다 |
| 붙는 충돌 | **V** = (*m*<sub>A</sub>*v*<sub>A</sub>, *m*<sub>B</sub>*v*<sub>B</sub>)/(*m*<sub>A</sub> + *m*<sub>B</sub>), tan *θ* = *m*<sub>B</sub>*v*<sub>B</sub>/(*m*<sub>A</sub>*v*<sub>A</sub>) |
| 운동 | 충돌 전 1.2 s, 충돌 뒤 1.2 s 동안 등속이다 |
| 채점 | 각은 1° 안, 속력은 2% 또는 0.01 안이면 정답. *b*/*r*로 구한 각, 여각, 퍽 1의 속력을 그대로 넘긴 값, 정면 충돌 값, 질량 없이 속도 비로 구한 각, 운동량 크기를 그냥 더한 속력을 따로 알려 준다 |
| 시험 | `model.test.js` 4개. Sample Problem 9.8.1(tan *θ* = 0.834, *θ* = 39.8°, *V* ≈ 4.9 km/h), 비켜 맞는 충돌의 *x*·*y* 운동량과 운동에너지 보존(식 9.8.3–9.8.5), *θ*<sub>2</sub> = sin⁻¹(*b*/2*r*), 충돌 순간 두 중심 거리 2*r*, 같은 질량의 90°, 정면 충돌, 붙는 충돌의 운동량, 채점 |

Sample Problem 값은 시험에만 쓰고 화면에는 쓰지 않는다. Sample Problem 9.8.1의 *V* = 4.86 km/h는 반올림한 39.8°로 나눈 값이고 반올림 없이 계산하면 4.855 km/h다. 시험은 4.9 km/h와 0.2% 허용으로 대조했다. 영어 용어(two-dimensional collision, glancing collision, linear momentum, completely inelastic collision)는 교재 `c09`에서 확인했다.
