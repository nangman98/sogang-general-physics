# 5-1 알짜힘과 자유물체도

교재 Principles of Physics 12e, Chapter 5, Module 5.1 Newton’s First and Second Laws와 Module 5.2 Some Particular Forces 화면이다. 활동은 둘이고 둘 다 재생 전에 예측하고 확인한다.

| 활동 | 학생이 하는 일 | 교재 대응 |
|---|---|---|
| 알짜힘 | 마찰 없는 면 위 상자에 수평 힘이 2–3개 걸린 문제 5개 가운데 하나를 고른다. 회색 예측 화살표를 돌려 가속도 방향을 정하고 크기 *a*를 적은 뒤 확인한다. 확인하면 힘을 꼬리에서 머리로 이은 합, *F⃗*<sub>net</sub>, *a⃗*가 나타나고 재생하면 상자가 정지 상태에서 출발한다 | Eq. (5.1.1), (5.1.2), (5.1.6), (5.2.7), LO 5.1.1, 5.1.2, 5.1.3, 5.1.6 |
| 자유물체도 | 줄로 비스듬히 끄는 상자의 *m*, *T*, *θ*, *f*를 정하고 수직항력 *F<sub>N</sub>*과 가속도 *a<sub>x</sub>*를 먼저 적는다. 확인하면 *F⃗*<sub>net</sub>와 *a⃗*가 나타나고 재생하면 상자가 미끄러진다 | Eq. (5.2.1), (5.1.2), LO 5.2.1, 5.2.4, 5.2.5, 5.2.6 |

## 모델

| 항목 | 내용 |
|---|---|
| 좌표 | *x* 오른쪽, *y* 위, *z* 화면 밖(`06_3D_무대_기준.md`). 바닥은 *x*–*z* 평면이다 |
| 알짜힘 식 | *F⃗*<sub>net</sub> = Σ*F⃗*, *a⃗* = *F⃗*<sub>net</sub>/*m*. 상자는 정지에서 출발해 *r⃗* = ½*a⃗t*²로 움직인다 |
| 힘 문제 5개 | 질량 0.50–1.25 kg, 힘 4–12 N. 문제마다 오답 세 가지(가장 큰 힘의 방향, 크기를 그냥 더한 값, *F*<sub>net</sub>을 *a*로 쓴 값)가 정답과 다르다. 문제 4는 알짜힘이 0이다 |
| 알짜힘 채점 | 방향은 정답과 10° 안, 크기는 2% 또는 0.01 m/s² 안이면 정답. 가장 큰 힘 방향, 크기 합, 질량으로 안 나눈 값, 알짜힘 0을 놓친 경우는 따로 알려 준다 |
| 끄는 상자 식 | *y* 성분 *F<sub>N</sub>* + *T* sin *θ* − *F<sub>g</sub>* = 0, *x* 성분 *T* cos *θ* − *f* = *ma<sub>x</sub>*. *T*의 상한은 *F<sub>N</sub>* ≥ 0이 되도록 *m*과 *θ*에서 정한다 |
| 마찰 | 5.2 범위만 쓴다. 상자는 처음 속도 1.00 m/s로 +*x* 방향으로 미끄러지는 중이고 *f⃗*는 면에 나란한 반대 방향, 크기는 slider 값이다. 상자가 멈추면 그 자리에 정지해 있다(*T* cos *θ* < *f*) |
| 끄는 상자 채점 | 두 값 모두 2% 또는 0.01 안이면 정답. *F<sub>N</sub>* = *mg*, *F<sub>N</sub>* = *mg* + *T* sin *θ*, *T* 전체를 쓴 *a*, 마찰을 뺀 *a*, 부호 반대는 따로 알려 준다 |
| *g* | 9.8 m/s² |
| 재생 | 일시정지할 때까지 움직인다(시간 slider는 0–60 s). 알짜힘 활동은 상자를 가운데에 두고 바닥 격자가, 자유물체도 활동은 상자를 제자리에 두고 측정대 눈금과 거리 숫자가 흐른다. 학과의 이전 뉴턴 제2법칙 실험실 방식이다 |
| slider 범위 | *m* 1–20 kg, *T* 0–200 N(상자가 뜨지 않는 값까지), *θ* 0–90°, *f* 0–100 N |
| 예측 전 표시 | 구할 힘 *F⃗<sub>N</sub>*은 확인 전까지 회색 고정 길이(1 m)와 "= ?"로 그린다. 다른 힘은 자유물체도에 크기를 함께 적는다 |
| 시험 | `model.test.js` 10개. Sample Problem 5.1.1(*a<sub>x</sub>* = 0.542 m/s², *v* = 1.6 m/s, *F<sub>x</sub>* = −171 N), 5.1.2(*F⃗*<sub>3</sub> = (12.5 N)î − (10.4 N)ĵ, 16 N, −40°), 5.2.1(*a<sub>x</sub>* = 40.1 m/s², *ϕ* = 76°), 5.3.4(*F<sub>N</sub>* = 708 N, 939 N, 477 N, *F*<sub>net</sub> = 231 N), 문제 5개의 값, 두 채점, *F<sub>N</sub>* ≥ 0, 운동 |

Sample Problem 값은 시험에만 쓰고 화면에는 쓰지 않는다. 5.3.4는 Module 5.3 문제지만 식 (5.2.6)과 같은 *F<sub>N</sub>* = *m*(*g* + *a<sub>y</sub>*)를 대조하려고 넣었다. 영어 용어(net force, free-body diagram, gravitational force, normal force, frictional force, tension, frictionless surface, particle, Newton’s First Law)는 교재 `c05`에서 확인했다.
