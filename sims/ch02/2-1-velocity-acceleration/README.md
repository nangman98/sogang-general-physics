교재 Principles of Physics 12e, Chapter 2, Module 2.1–2.3 (Learning Objectives 2.1.4, 2.1.6, 2.2.1–2.2.3, 2.3.1–2.3.3) 화면이다. 활동은 셋이다.

| 활동 | 학생이 하는 일 | 교재 대응 |
|---|---|---|
| 평균과 순간 | *x*–*t* 판이나 *v*–*t* 판을 고르고 시작 시각 *t*₁과 시간 간격 Δ*t*를 정한다. P와 Q를 잇는 할선의 기울기가 *v*<sub>avg</sub> (또는 *a*<sub>avg</sub>)로 나온다. Δ*t*를 줄여 할선 기울기가 다가가는 값을 적고 확인하면 P의 접선과 숨겨 둔 *v*–*t* 곡선이 나타난다 | Eq. (2.1.1), (2.1.2), (2.2.1), (2.3.1), (2.3.2), LO 2.1.4, 2.1.6, 2.2.1, 2.2.2, 2.3.1–2.3.3 |

## 모델

| 항목 | 내용 |
|---|---|
| 운동 다섯 가지 | 정지 뒤 출발 *x* = −8 (*t* ≤ 2 s), −8 + (*t* − 2)³/12 (*t* > 2 s). 등속 *x* = 6 − 1.5*t*. 가속 *x* = −9 + 0.5*t* + 0.25*t*². 감속해 되돌아옴 *x* = −8 + 6*t* − 0.75*t*². 앞뒤 왕복 *x* = 8 sin(π*t*/4). *x*는 m, *t*는 s다 |
| 도함수 | *v*와 *a*는 해석적 도함수다. 수치 미분 대조는 시험에서 한다 |
| 시간 범위 | 0–8 s |
| 할선 | *t*₂ = *t*₁ + Δ*t*, Δ*t*는 0.01–2 s, *t*₁은 0–6 s |
| 추정 채점 | 접선 기울기와 0.05 또는 2% 안이면 정답. 아직 넓은 Δ*t*의 할선 기울기, 부호 반대, 판의 높이 (*x*₁ 또는 *v*₁), *x*₁/*t*₁은 따로 알려 준다. 답 보기 단추가 있다 |
| 부호 채점 | \|*v*\| < 10⁻⁹ m/s면 *v* = 0으로 본다 |
| 속력 채점 | *v*와 *a*의 부호가 같으면 커진다, 다르면 작아진다. 네 시각은 1, 3, 5, 7 s이고 부호 조합이 모두 다르다 |
| 시험 | `model.test.js` 10개 (도함수 대조, Δ*t* → 0 극한, Sample Problem 2.1.1·2.2.1·2.3.1의 답, 교재 Signs 단락의 *v* = −25 m/s 예, 추정 채점, 부호 채점, 속력 채점과 오답 유형 2가지, 기본값) |

Sample Problem 값은 시험에만 쓰고 화면에는 쓰지 않는다. Sample Problem 2.2.1의 엘리베이터 *x*(*t*)는 Fig. 2.2.1c의 *a*(*t*) (1–3 s에 +2 m/s², 8–9 s에 −4 m/s²)로 다시 만들어 기울기 +4.0 m/s와 Δ*x* = +20 m를 확인했다. 괄호 영어 용어는 교재 c02 추출문에서 찾았다. 접선과 할선은 c02에 영어 표기가 없어 괄호를 붙이지 않았다.

## 오개념

속력 변화 활동은 속도와 가속도의 방향이 반드시 같다고 보는 오개념을 겨냥한다. 근거는 Rosenblatt·Heckler (2011), Physical Review Special Topics – Physics Education Research 7, 020112, DOI 10.1103/PhysRevSTPER.7.020112다. Codex 문헌표 `93_Codex/01_단원별_오개념_문헌.md`에 본문 확인으로 적힌 문헌이다. 화면에는 문헌 이름을 쓰지 않는다.
