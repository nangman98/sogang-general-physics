# 11-5 자이로스코프의 세차

교재 Principles of Physics 12e, Chapter 11, Module 11.9 Precession of a Gyroscope 화면이다. 받침점 O 위 수평 축에 달린 바퀴가 빠르게 자전하며 연직축 둘레로 세차한다. 학생은 재생 전에 세차 각속도와 세차 방향을 예측하고 채점받는다.

| 활동 | 학생이 하는 일 | 교재 대응 |
|---|---|---|
| 세차 | 자전 방향, 바퀴 질량 *M*과 반지름 *R*<sub>w</sub>, 받침점에서 바퀴 중심까지 거리 *r*, 자전 각속도 *ω*를 정한다. *Ω*를 적고 위에서 본 세차 방향을 고른다 | Eq. (11.9.2)–(11.9.4), (11.9.6), Checkpoint 11.9.1, LO 11.9.1–11.9.3 |

## 모델

| 항목 | 내용 |
|---|---|
| 세차 | *I* = ½*MR*<sub>w</sub>², *L* = *Iω*, *τ* = *Mgr*, *Ω* = *Mgr*/*Iω* = 2*gr*/(*R*<sub>w</sub>²*ω*). 질량이 지워진다 |
| 방향 | *dL* = *τ dt*이고 *τ* = *r* × *Mg*다. *L*이 O에서 바퀴 쪽을 향하면 위에서 볼 때 시계 반대 방향, 반대면 시계 방향이다 |
| 가정 | 축은 수평이고 질량을 무시한다. O는 움직이지 않는다. 세차에 따른 각운동량은 무시한다(*ω* ≫ *Ω*, 슬라이더 범위에서 *ω*/*Ω* ≥ 14.6). *g* = 9.8 m/s² |
| 채점 | 2% 또는 0.01 안이면 정답. 분자와 분모를 바꾼 *Iω*/*Mgr*, 고리 관성모멘트로 얻은 *Ω*/2, 2π를 곱한 값을 따로 알려 준다 |
| 시험 | `model.test.js` 4개. 식 (11.9.6)과 질량 무관(*M* = 0.5, 3 kg), Checkpoint 11.9.1의 경향(*ω*, *M*, *g*), 두 자전 방향에서 중앙 차분 d*L*/d*t*와 *r* × *Mg*의 일치와 일정한 \|*L*\|, 채점 |

Module 11.9에는 Sample Problem이 없다. 영어 용어(gyroscope, precession, precession rate, spin, moment arm)는 교재 `c11`에서 확인했다.
