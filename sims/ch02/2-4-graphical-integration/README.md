# 2-4 그래프 적분

교재 Principles of Physics 12e, Chapter 2, Module 2.6 Graphical Integration in Motion Analysis (Learning Objectives 2.6.1–2.6.2) 화면이다. 활동은 셋이다.

| 활동 | 학생이 하는 일 | 교재 대응 |
|---|---|---|
| 속도 변화 | *a*(*t*)를 2 s 계단 네 개로 정한다. 재생하기 전에 *a*–*t* 넓이를 더해 *t* = 8 s의 *v*를 적고 확인한다. 재생하면 넓이가 쌓이며 *v*–*t* 곡선과 *x*–*t* 곡선이 그려진다 | Eq. (2.6.1), (2.6.2), LO 2.6.1 |
| 변위 | 재생하기 전에 *v*–*t* 넓이로 8 s까지의 변위를 적고 확인한다. 축 아래 넓이만큼 자동차가 되돌아간다. 전체 거리와 평균 속력 *s*<sub>avg</sub>, 평균 속도 *v*<sub>avg</sub>를 같이 보여 준다 | Eq. (2.6.3), (2.6.4), (2.1.3), LO 2.6.2 |
| 정지선 | 정지선 네 곳 중 하나를 고르고 *t* = 8 s에 그 자리에서 *v* = 0으로 멈추도록 계단 값을 맞춘 뒤 확인한다 | Eq. (2.6.1), (2.6.3) |

## 모델

| 항목 | 내용 |
|---|---|
| 가속도 | 0–2, 2–4, 4–6, 6–8 s 구간마다 일정, −5–5 m/s², 0.5 m/s² 간격. 기본값 2, 0, −3, 0.5 m/s² |
| 처음 값 | *v*₀ = 0, *x*₀ = 0 |
| 넓이 | 꺾은선 함수의 넓이를 정확히 구한다. 곡선이 시간축을 지나는 곳에서 조각을 나누고 조각마다 부호를 붙인다. *v*(*t*)는 꺾은선, *x*(*t*)는 그 넓이의 누적이다 |
| 전체 거리 | 넓이 조각의 크기를 부호 없이 더한다. 평균 속력은 식 (2.1.3) |
| 속도 채점 | 1% 또는 0.05 m/s 안이면 정답. 넓이의 크기만 더한 답, Δ*t*를 곱하지 않은 답, 부호 반대는 따로 알려 준다 |
| 변위 채점 | 1% 또는 0.1 m 안이면 정답. 전체 거리를 적은 답, *v*(8 s) × 8 s, 부호 반대는 따로 알려 준다 |
| 정지선 | *x* = 12, 20, −8, 6 m. *v*(8 s) = 0이고 위치가 0.25 m 안이면 정답. 네 곳 모두 slider 간격으로 닿을 수 있음을 시험에서 13⁴ 조합을 다 찾아 확인했다 |
| 시험 | `model.test.js` 8개 (Sample Problem 2.6.1의 넓이 0, 1.5, 0.50 m/s와 *v*₁ = 2.0 m/s, Sample Problem 2.2.1 식 (2.2.3)의 +20 m, Sample Problem 2.1.1의 16.0 km와 12.8 km/h, 정확한 넓이와 Simpson 수치 적분의 일치, 기본값의 넓이 조각, 두 채점, 정지선) |

Sample Problem 값은 시험에만 쓰고 화면에는 쓰지 않는다. 괄호 영어 용어는 교재 c02 추출문에서 찾았다.
