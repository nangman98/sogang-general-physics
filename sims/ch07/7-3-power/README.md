# 7-3 일률

교재 Principles of Physics 12e, Chapter 7, Module 7.6 Power 화면이다. 일률은 힘이 일을 하는 빠르기이고 일정한 힘에서는 *P* = *Fv* cos *φ*다. 활동은 둘이고 둘 다 재생 전에 예측하고 채점한다.

| 활동 | 학생이 하는 일 | 교재 대응 |
|---|---|---|
| 한 힘의 일률 | 질량 *m*, 당기는 힘 *F*, 각 *φ*, 처음 속력 *v*<sub>i</sub>를 정한다. 처음 순간의 일률과 4 s 동안의 평균 일률을 적는다 | Eq. (7.6.1), (7.6.2), (7.6.6), LO 7.6.1–7.6.3 |
| 두 힘의 일률 | 운동과 반대인 수평 힘 *F*<sub>1</sub>, 각 *φ*<sub>2</sub>로 당기는 *F*<sub>2</sub>, 속력 *v*를 정한다. 그 순간의 *P*<sub>1</sub>, *P*<sub>2</sub>를 적고 알짜 일률이 어떻게 변하는지 고른다 | Eq. (7.6.6), (7.6.7), Sample Problem 7.6.1의 배치, LO 7.6.3 |

## 모델

| 항목 | 내용 |
|---|---|
| 운동 | 마찰 없는 바닥. *F*<sub>x,net</sub>이 일정하므로 *v* = *v*<sub>0</sub> + (*F*<sub>x,net</sub>/*m*)*t*, *x* = *v*<sub>0</sub>*t* + ½(*F*<sub>x,net</sub>/*m*)*t*². 4 s 동안 재생하고 상자가 그 전에 멈추면 거기서 끝낸다 |
| 일률 | *P* = *Fv* cos *φ*(식 7.6.6). *P*<sub>1</sub> = −*F*<sub>1</sub>*v*, *P*<sub>2</sub> = *F*<sub>2</sub>*v* cos *φ*<sub>2</sub>, *P*<sub>net</sub> = *F*<sub>x,net</sub>*v*. 평균 일률 *P*<sub>avg</sub> = *W*/Δ*t*(식 7.6.1), *W* = *F* cos *φ* Δ*x* |
| 알짜 일률의 변화 | d*P*<sub>net</sub>/d*t* = *F*<sub>x,net</sub>²/*m*. 알짜힘이 0이면 일정하다. 알짜힘이 0이 아니면 늘 커진다(음수이면 0 쪽으로). 화면은 이것을 "커진다", "일정하다"로 채점한다 |
| slider 제한 | 위로 당기는 힘은 *F* sin *φ* < 0.95 *mg*로 막아 상자가 바닥에서 뜨지 않는다 |
| 채점 | 2% 또는 0.01 안이면 정답. cos를 빠뜨리거나 sin을 쓴 일률, 마지막이나 처음 순간의 일률을 평균으로 쓴 값, 일을 시간으로 나누지 않은 값, 부호가 바뀐 *P*<sub>1</sub>을 따로 알려 준다 |
| 시험 | `model.test.js` 6개. Sample Problem 7.6.1(*P*<sub>1</sub> = −6.0 W, *P*<sub>2</sub> = +6.0 W, *P*<sub>net</sub> = 0, 일정), 7.6.2(80 hp, 11 m/s에서 5.4 × 10³ N), *P* = d*W*/d*t*와 *P*<sub>avg</sub> = *W*/Δ*t*(중앙 차분), 멈추는 상자, 알짜 일률이 커지는 경우, 채점, slider 전 범위 400조합 |

Sample Problem 값은 시험에만 쓰고 화면에는 쓰지 않는다. 영어 용어(power, average power, instantaneous power, watt)는 교재 `c07`에서 확인했다.
