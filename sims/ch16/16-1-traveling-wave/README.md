# 16-1 진행파와 줄의 파동 속력

교재 Principles of Physics 12e, Chapter 16, Module 16.1 Transverse Waves, 16.2 Wave Speed on a Stretched String 화면이다. 장력과 선밀도로 정해지는 파동 속력과 파장, 그리고 진행파가 지나가는 줄 요소의 가로 운동을 재생 전에 예측하고 채점한다. 활동은 둘이다.

| 활동 | 학생이 하는 일 | 교재 대응 |
|---|---|---|
| 파동 속력 | 장력 *τ*, 밧줄 질량 *m*(길이 *l* = 6.00 m), 진동수 *f*, 진폭 *y*<sub>m</sub>을 정한다. 파동 속력 *v*와 파장 *λ*를 적는다 | Eq. (16.1.2), (16.1.13), (16.2.5), *μ* = *m*/*l*, Sample Problem 16.2.1, LO 16.1.8–16.1.9, 16.2.1–16.2.2 |
| 줄 요소의 운동 | 진폭 *y*<sub>m</sub>, 파장 *λ*, 진동수 *f*를 정한다. *x* = 0인 줄 요소의 최대 가로 속력 *u*<sub>max</sub>와 그 요소가 처음 *y* = +*y*<sub>m</sub>에 닿는 시각을 적는다 | Eq. (16.1.2), (16.1.5), (16.1.6), (16.1.8), (16.1.13), (16.1.20), (16.1.21), Sample Problem 16.1.1, 16.1.2, LO 16.1.3–16.1.4, 16.1.6, 16.1.10–16.1.11 |

## 모델

| 항목 | 내용 |
|---|---|
| 파동 속력 | *μ* = *m*/*l*, *v* = √(*τ*/*μ*), *λ* = *v*/*f* |
| 흔들기 시작한 밧줄 | 처음에 곧고 정지한 밧줄의 왼쪽 끝을 *t* = 0부터 *y* = −*y*<sub>m</sub> sin *ωt*(Eq. 16.1.6)로 흔든다. 밧줄의 변위는 *x* ≤ *vt*에서 *y*<sub>m</sub> sin(*kx* − *ωt*), 그 앞에서 0이다. Eq. (16.1.17)의 꼴 *h*(*kx* − *ωt*)이므로 진행파이고 맨 앞이 *v*로 간다. 맨 앞이 오른쪽 끝에 닿는 *t* = *l*/*v*에서 재생을 멈춘다 |
| 줄 요소 | *y* = *y*<sub>m</sub> sin(*kx* − *ωt*), *u* = −*ωy*<sub>m</sub> cos(*kx* − *ωt*), *a*<sub>y</sub> = −*ω*²*y*<sub>m</sub> sin(*kx* − *ωt*). *x* = 0에서 *y* = −*y*<sub>m</sub> sin *ωt*라 처음 가장 높은 곳에 닿는 시각은 3*T*/4다 |
| 범위 | *τ* = 5–20 N, *m* = 1.2–4.8 kg(*μ* = 0.2–0.8 kg/m), *f* = 2.0–5.0 Hz로 *v* = 2.5–10 m/s, *λ* = 0.5–5 m가 밧줄 길이 6 m 안에 들어온다. 줄 요소 활동은 *λ* = 1.0–4.0 m, *f* = 1.0–3.0 Hz, 두 활동 모두 *y*<sub>m</sub> = 5–25 cm |
| 가정 | 마찰이 없는 이상적인 줄, 중력에 의한 처짐과 끝에서 되돌아오는 파동은 무시한다. 재생은 실제보다 4배 느리다(`timeScale` 0.25, `dt` = 1/960 s) |
| 채점 | 2% 또는 0.01 안이면 정답. 제곱근을 빠뜨린 *τ*/*μ*, 뒤집은 √(*μ*/*τ*), 선밀도 대신 질량을 쓴 √(*τ*/*m*), 파장 *vf*와 *v*/*ω*, 최대 가로 속력 대신 파동 속력 *v*, 2π를 빠뜨린 *fy*<sub>m</sub>, 최대 가속도 *ω*²*y*<sub>m</sub>, cm 그대로 쓴 값, 시각 *T*/4(처음에 위로 간다고 본 값), *T*/2, *T*를 따로 알려 준다. 기본값에서 정답과 각 실수 값은 2% 넘게 다르다 |
| 시험 | `model.test.js` 6개. Sample Problem 16.1.1, 16.1.2, 16.2.1, 흔들기 시작한 밧줄의 *v* = √(*τ*/*μ*) = *λf* = *ω*/*k*와 끝의 운동, 맨 앞 밖의 변위 0, 중앙 차분으로 확인한 파동 방정식 ∂²*y*/∂*t*² = *v*²∂²*y*/∂*x*²(Eq. 16.4.12)와 *u* = ∂*y*/∂*t*, 줄 요소가 3*T*/4에 처음 +*y*<sub>m</sub>에 닿음과 *u*<sub>max</sub> = *ωy*<sub>m</sub>, 채점 |

Sample Problem 값은 시험에만 쓰고 화면에는 쓰지 않는다. 16.1.1은 *k* = 200π rad/m와 *ω* = 100π rad/s를 확인한다. 화면이 위상 상수 *ϕ*를 다루지 않아 *ϕ* = −0.73 rad는 시험하지 않았다. 16.1.2의 *u* = 7.20 mm/s, *a*<sub>y</sub> = −14.2 mm/s²와 16.2.1의 1.77 × 10⁻³ s, 1.67 × 10⁻³ s는 교재 자릿수 그대로 맞는다. 교재 식 (16.1.20)은 분모가 ∂*x*로 인쇄되어 있으나 본문이 *t*로 미분한다고 적고 있어 화면에는 ∂*y*/∂*t*로 적었다. 영어 용어(transverse wave, string element, transverse velocity, linear density, tension, rope, peak)는 교재 `c16`에서 확인했다.
