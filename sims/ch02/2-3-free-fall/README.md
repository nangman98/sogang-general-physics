# 2-3 자유 낙하 가속도

교재 Principles of Physics 12e, Chapter 2, Module 2.5 Free-Fall Acceleration (Learning Objectives 2.5.1–2.5.2) 화면이다. 활동은 셋이다.

| 활동 | 학생이 하는 일 | 교재 대응 |
|---|---|---|
| 던지고 보기 | 처음 속도 *v*₀와 던진 점의 높이 *h*를 정하고 재생한다. 같은 시간 간격 잔상으로 간격이 줄었다가 다시 늘어나는 것을 본다. 최고점과 던진 높이로 돌아온 순간에 표시가 나온다. 식 세 개에 현재 값이 들어간다 | LO 2.5.2, Table 2.4.1의 *y* 꼴 |
| 최고점 예측 | 재생하기 전에 최고점의 *v*와 *a*를 고른다. *a* = 0을 고르면 따로 알려 준다. 확인하면 *v*–*t* 판의 최고점에 기울기 삼각형 (1 s에 −9.8 m/s)이 나온다 | LO 2.5.1 |
| 대칭 | 올라간 시간과 내려온 시간, 던진 높이로 돌아온 순간의 속력을 먼저 고른다. 비교할 높이 *y*를 옮기면 그 높이를 지나는 두 시각과 두 속도가 나온다 | LO 2.5.2 |

## 모델

| 항목 | 내용 |
|---|---|
| 좌표 | +*y*는 위, 던진 점이 *y* = 0, 땅은 *y* = −*h* (교재 Sample Problem 2.5.1과 같은 관례) |
| 식 | *y* − *y*₀ = *v*₀*t* − ½*gt*², *v* = *v*₀ − *gt*, *v*² = *v*₀² − 2*g*(*y* − *y*₀). *a* = −*g*, *g* = 9.8 m/s²를 정확한 값으로 쓴다. 매 시각 정확한 해이고 적분기는 없다 |
| 식 번호 | 교재는 자유 낙하 식에 따로 번호를 붙이지 않고 Table 2.4.1의 식을 *y* 꼴로 쓴다 (Sample Problem 2.5.1의 "Eq. 2.4.5 (but in *y* notation)"). 화면 식 번호 칸에는 Table 2.4.1 번호 (2.4.5), (2.4.1), (2.4.6)을 적고 그 위에 바꿔 쓴 것임을 밝혔다 |
| 시간 범위 | 0부터 땅에 닿는 시각 (*v*₀ + √(*v*₀² + 2*gh*))/*g*까지 |
| 조절 범위 | *v*₀는 −10–25 m/s (최고점 예측과 대칭은 2–25 m/s), *h*는 5–50 m. 기본값 *v*₀ = 10 m/s, *h* = 12 m |
| 잔상 | 올라가는 시간을 3–8칸으로 똑같이 나눈 간격 (기본값 0.204 s). 그래서 내려올 때 잔상이 올라갈 때 잔상과 같은 높이에 온다. 올라갈 때는 반투명 공, 내려올 때는 고리로 그려 모양으로 구분한다. 아래로 던지면 0.25 s 간격 |
| 시험 | `model.test.js` 10개 (*g* = 9.8 m/s², Sample Problem 2.5.1의 3.1 s와 약 −31 m/s, Fig. 2.5.2 표의 *t* = 1, 2, 3 s 값, Table 2.4.1 다섯 식의 *y* 꼴 일치, 최고점, 대칭, 잔상 높이, 두 채점, 기본값) |

Sample Problem 값과 Fig. 2.5.2 표 값은 시험에만 쓰고 화면에는 쓰지 않는다. 괄호 영어 용어는 교재 c02 추출문에서 찾았다. 최고점에서 *a* = 0을 고르는 오개념의 문헌 출처는 아직 확인하지 못해 화면과 이 문서에 쓰지 않았다.
