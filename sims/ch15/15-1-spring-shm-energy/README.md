# 15-1 단순 조화 운동과 에너지

교재 Principles of Physics 12e, Chapter 15, Module 15.1 Simple Harmonic Motion과 Module 15.2 Energy in Simple Harmonic Motion 화면이다. 마찰 없는 바닥에서 용수철에 매인 블록(선형 진동자, Fig. 15.1.7)의 주기와 속도 진폭을 재생 전에 구하고 채점한다. 확인 뒤 위치·속도·가속도 그래프와 에너지 막대가 나타난다.

| 활동 | 학생이 하는 일 | 교재 대응 |
|---|---|---|
| 용수철–블록 | 질량 *m*, 용수철 상수 *k*, 진폭 *x*<sub>m</sub>, 처음 위치(위상 상수 *ϕ*)를 정한다. 주기 *T*와 속도 진폭 *v*<sub>m</sub>을 적는다 | Eq. (15.1.3)–(15.1.13), (15.2.1)–(15.2.4), Fig. 15.1.4, 15.1.6, 15.2.1a, LO 15.1.2–15.1.15, 15.1.17–15.1.18, 15.2.1–15.2.4 |

## 모델

| 항목 | 내용 |
|---|---|
| 운동 | *x* = *x*<sub>m</sub> cos(*ωt* + *ϕ*), *v* = −*ωx*<sub>m</sub> sin(*ωt* + *ϕ*), *a* = −*ω*²*x*<sub>m</sub> cos(*ωt* + *ϕ*), *F* = −*kx*, *ω* = √(*k*/*m*), *T* = 2π√(*m*/*k*). 닫힌 식이라 적분하지 않는다 |
| 위상 상수 | 처음 위치 네 가지가 Fig. 15.1.4의 *ϕ* = 0, π/2, π, 3π/2 rad다(+*x*<sub>m</sub>, 0에서 −*x* 방향, −*x*<sub>m</sub>, 0에서 +*x* 방향) |
| 에너지 | *U* = ½*kx*², *K* = ½*mv*², *E* = *U* + *K* = ½*kx*<sub>m</sub>² |
| 범위 | *m* 0.2–2.0 kg, *k* 5–50 N/m, *x*<sub>m</sub> 4–20 cm. *T*는 0.397–3.97 s다. 재생은 주기와 상관없이 5 s 동안이라 시간 축 끝과 시간 막대 끝값으로 주기가 드러나지 않는다 |
| 가정 | 바닥 마찰과 공기 저항이 없다. 용수철은 질량이 없고 블록은 변형되지 않는다. *x*는 평형 위치에서 재고 오른쪽이 +다 |
| 채점 | 2% 또는 0.01 안이면 정답. *T*는 √(*k*/*m*)을 쓴 2π√(*k*/*m*), 2π를 뺀 1/*ω*, 진동수 *f*, 각진동수 *ω*를 따로 알려 준다. *v*<sub>m</sub>은 진폭 *x*<sub>m</sub>, 가속도 진폭 *ω*²*x*<sub>m</sub>, *f x*<sub>m</sub>, cm 값을 그대로 곱한 값을 따로 알려 준다. 기본값(*m* = 0.8 kg, *k* = 20 N/m, *x*<sub>m</sub> = 10 cm)에서 *T* = 1.26 s, *v*<sub>m</sub> = 0.500 m/s이고 실수 값(31.4, 0.200, 0.796, 5.00 / 0.100, 2.50, 0.0796, 50.0)은 모두 2% 넘게 다르다 |
| 시험 | `model.test.js` 9개. 중앙 차분으로 *v* = d*x*/d*t*, *a* = d*v*/d*t* = −*ω*²*x*, *F* = *ma* = −*kx* 확인, 주기 *T* 뒤 같은 상태, 처음 위치 네 가지의 위치와 방향, 모든 시각에서 *K* + *U* = ½*kx*<sub>m</sub>², Sample Problem 네 개, 채점 |

Sample Problem 15.1.1(*T* = 0.35 s), 15.1.2(*ω* = 23.5 rad/s, *ϕ* = 155°, *x*<sub>m</sub> = 9.4 cm), 15.2.1(*E* ≈ 2.1 × 10⁷ J, *v* = 12.6 m/s), 15.2.2(*E* = 0.393 J, *U* = 0.098 J, *K* ≈ 0.30 J)는 시험에만 쓰고 화면 기본값으로 쓰지 않는다. 15.2.1에서 교재는 *k* = 1.073 × 10⁹ N/m(계산값 1.0738 × 10⁹)로 *E* = 2.147 × 10⁷ J를 냈고 계산값으로는 2.148 × 10⁷ J다. 15.2.2의 *K*는 반올림 전 0.295 J다. 영어 용어(simple harmonic motion, linear oscillator, amplitude, phase constant, angular frequency, velocity amplitude, spring constant, equilibrium position, mechanical energy)는 교재 `c15`에서 확인했다.
