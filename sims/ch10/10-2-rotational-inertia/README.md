# 10-2 관성모멘트

교재 Principles of Physics 12e, Chapter 10, Module 10.5 Calculating the Rotational Inertia 화면이다. 같은 돌림힘을 받는 물체의 각가속도가 관성모멘트에 반비례하는 것으로 모양과 회전축 위치의 효과를 본다. 활동은 둘이고 둘 다 재생 전에 예측하고 채점한다.

| 활동 | 학생이 하는 일 | 교재 대응 |
|---|---|---|
| 모양 비교 | 두 물체 A, B의 모양(고리, 원판, 속이 찬 구, 얇은 구 껍질, 막대)과 공통의 *M*, *R*, 돌림힘 *τ*를 정한다. 어느 쪽이 더 빨리 돌기 시작하는지 고르고 A의 각가속도를 적는다 | Eq. (10.4.3), (10.7.4), Table 10.5.1, LO 10.5.1, 10.5.2 |
| 평행축 정리 | 막대 길이 *L*, 질량 *M*, 축과 중심 사이 거리 *h*, 돌림힘을 정한다. 관성모멘트와 각가속도를 적는다 | Eq. (10.5.2), Sample Problem 10.5.1, 10.5.2, LO 10.5.3 |

## 모델

| 항목 | 내용 |
|---|---|
| 관성모멘트 | 고리 *MR*², 원판 ½*MR*², 속이 찬 구 ⅖*MR*², 얇은 구 껍질 ⅔*MR*²(Table 10.5.1), 길이 2*R* 막대의 중심축 (1/12)*M*(2*R*)² = ⅓*MR*². 평행축 *I* = *ML*²/12 + *Mh*²(식 10.5.2) |
| 운동 | 정지에서 *α* = *τ*/*I*(식 10.7.4)로 3 s 동안 돈다. *ω* = *αt*, *θ* = ½*αt*² |
| 가정 | 축 마찰이 없다. 두 물체의 *M*, *R*는 같다. 막대는 가늘고 고르다 |
| 채점 | 각가속도와 관성모멘트는 2% 또는 0.001 안이면 정답. 어느 모양에나 *MR*²를 쓴 값, *τI*, *R*로 한 번 더 나눈 값, 평행축 항을 빠뜨리거나 그것만 쓴 값, 끝을 지나는 축의 값을 따로 알려 준다 |
| 시험 | `model.test.js` 4개. Sample Problem 10.5.1(질점 두 개의 ½*mL*²와 *mL*², 평행축 정리로도 같음), 10.5.2(막대 *ML*²/12를 20000칸 합으로, 끝 축 *ML*²/3), Table 10.5.1 계수와 *α* = *τ*/*I*, 같은 모양이면 같은 빠르기, 채점 |

Sample Problem 값은 시험에만 쓰고 화면에는 쓰지 않는다. 영어 용어(rotational inertia, parallel-axis theorem, hoop, solid cylinder, solid sphere, thin spherical shell, thin rod, torque)는 교재 `c10`에서 확인했다.
