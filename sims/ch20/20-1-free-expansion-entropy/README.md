# 20-1 자유 팽창과 등온 팽창의 엔트로피

교재 Principles of Physics 12e, Chapter 20, Module 20.1 Entropy 화면이다. 같은 처음 상태 i와 나중 상태 f를 잇는 비가역 자유 팽창과 가역 등온 팽창을 나란히 놓고 두 과정의 엔트로피 변화가 같음을 확인한다. 활동은 하나이고 재생 전에 예측하고 채점한다.

| 활동 | 학생이 하는 일 | 교재 대응 |
|---|---|---|
| 두 팽창 | 몰수 *n*, 온도 *T*, 처음 부피 *V*<sub>i</sub>, 부피 비 *V*<sub>f</sub>/*V*<sub>i</sub>를 정한다. 등온 팽창에서 기체가 저장고에서 받는 열 *Q*와 자유 팽창의 엔트로피 변화 Δ*S*를 적는다 | Eq. (20.1.1), (20.1.2), (20.1.4), (19.2.10), Sample Problem 20.1.2, LO 20.1.2, 20.1.3, 20.1.6, 20.1.7 |

## 모델

| 항목 | 내용 |
|---|---|
| 등온 팽창 | Δ*E*<sub>int</sub> = 0이므로 *Q* = *W* = *nRT* ln(*V*<sub>f</sub>/*V*<sub>i</sub>)(Eq. 19.2.10, 19.7.9), Δ*S* = *Q*/*T* = *nR* ln(*V*<sub>f</sub>/*V*<sub>i</sub>)(Eq. 20.1.2). 재생 중 ln *V*가 시간에 비례해 *Q*가 고르게 늘어난다 |
| 자유 팽창 | *Q* = *W* = 0, *T*<sub>f</sub> = *T*<sub>i</sub>(Eq. 19.9.10). 같은 i와 f를 잇는 가역 과정의 Δ*S*를 쓰므로 Δ*S* = *nR* ln(*V*<sub>f</sub>/*V*<sub>i</sub>)(Eq. 20.1.1). 중간 상태는 평형이 아니어서 끝 상태에 이른 뒤에만 값을 보인다 |
| 범위 | *n* 0.5–3 mol, *T* 250–500 K, *V*<sub>i</sub> 5–20 L, *V*<sub>f</sub>/*V*<sub>i</sub> 1.5–4. *R* = 8.31 J/mol·K(Eq. 19.2.2). 압력은 kPa, 부피는 L로 보인다 |
| 분자 | 자유 팽창 상자에 분자 60개를 그린다. 시드를 고정한 의사난수로 처음 위치와 속도를 정하고 벽에서 거울 반사하는 직선 운동을 닫힌 식으로 구한다. 분자끼리는 부딪치지 않는다. 칸막이를 치우고 1.5 s 뒤부터 오른쪽 칸 분자 비율이 1 − *V*<sub>i</sub>/*V*<sub>f</sub> 근처에 머문다 |
| 가정 | 재생 시간 6 s는 과정의 순서만 보인다. 0.5 s에 칸막이를 치우고 등온 팽창은 0.5–5.5 s에 진행한다 |
| 채점 | 2% 또는 0.01 안이면 정답. *Q*에서 0, 상용로그, 처음 압력으로 구한 *p*<sub>i</sub>Δ*V*, *n*을 빠뜨린 값을 따로 알려 준다. Δ*S*에서 0(*Q* = 0을 그대로 넣은 값), *T*로 나누지 않은 값, 부호가 바뀐 값, 상용로그를 따로 알려 준다 |
| 시험 | `model.test.js` 5개. Sample Problem 20.1.2(+5.76 J/K), 경로 위 *pV* = *nRT*와 *Q* = ∫*p dV*의 Simpson 적분, 정압 팽창 뒤 정적 냉각이라는 다른 가역 경로의 Δ*S* = ∫*dQ*/*T*가 같은 값(상태 함수), 분자가 상자 안에 있고 열기 전에는 왼쪽 칸에만 있으며 연 순간 위치가 이어짐, 채점 |

Sample Problem 20.1.2(1.00 mol 질소의 부피가 두 배)는 시험에만 쓰고 화면 기본값은 *n* = 2.0 mol, *V*<sub>f</sub>/*V*<sub>i</sub> = 3이다. 교재 Sample Problem 20.4.2는 같은 문제를 20.1.1로 가리키지만 `c20` 본문 순서로는 20.1.2다. 영어 용어(free expansion, isothermal expansion, thermal reservoir, lead shot, state function)는 교재 `c19`, `c20`에서 확인했다.
