## 3D 모형

기준 물체는 `objects3d.js`의 모형으로 그린다. 외부 이미지·모형 파일은 쓰지 않고 three.js 기본 도형과 코드로 만든 무늬(지구·달·태양 표면)로 만들었다. 모형마다 특성 길이(지름, 키, 거리)가 1이 되게 만들고 장면에서 실제 크기 비로 늘이고 줄인다. 질량 모드는 같은 질량의 물 정육면체 옆에 물체를 실제 크기로 두고, 시간 모드는 빛 막대 옆에 사건 아이콘을 둔다(빛이 간 거리가 곧 물체 크기인 양성자·서울–부산·태양–지구는 같은 축척).
