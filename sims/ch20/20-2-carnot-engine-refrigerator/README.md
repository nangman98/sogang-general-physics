# 20-2 카르노 기관과 냉동기

교재 Principles of Physics 12e, Chapter 20, Module 20.2 Entropy in the Real World – Engines, 20.3 Refrigerators and Real Engines 화면이다. 단원자 이상 기체가 두 열 저장고 사이에서 카르노 순환을 돌며 열을 일로 바꾸는 기관과 같은 순환을 거꾸로 돌려 차가운 쪽에서 열을 뺏는 냉동기를 본다. 활동은 둘이고 둘 다 재생 전에 예측하고 채점한다.

| 활동 | 학생이 하는 일 | 교재 대응 |
|---|---|---|
| 카르노 기관 | *T*<sub>H</sub>, *T*<sub>L</sub>, 몰수 *n*, 등온 팽창의 부피 비 *V*<sub>b</sub>/*V*<sub>a</sub>를 정한다. 주어진 \|*Q*<sub>H</sub>\|로 효율 *ε*와 한 순환에 저온 저장고로 버리는 열 \|*Q*<sub>L</sub>\|을 적는다 | Eq. (20.2.1)–(20.2.6), (19.2.10), Sample Problem 20.2.1, 20.2.2, LO 20.2.2–20.2.6 |
| 카르노 냉동기 | 방(고온 저장고)과 냉동실(저온 저장고)의 온도, *n*, 부피 비를 정한다. 주어진 \|*Q*<sub>L</sub>\|로 성능 계수 *K*와 한 순환에 해 주어야 하는 일 \|*W*\|을 적는다 | Eq. (20.3.1)–(20.3.3), (20.2.3), LO 20.3.2–20.3.4 |

## 모델

| 항목 | 내용 |
|---|---|
| 순환 | 기관은 ab 등온 팽창(*T*<sub>H</sub>), bc 단열 팽창, cd 등온 압축(*T*<sub>L</sub>), da 단열 압축. 단열 과정은 *TV*<sup>*γ*−1</sup>이 일정하다(Eq. 19.9.4). 냉동기는 같은 네 상태를 a → d → c → b → a로 돈다 |
| 열과 일 | \|*Q*<sub>H</sub>\| = *nRT*<sub>H</sub> ln(*V*<sub>b</sub>/*V*<sub>a</sub>), \|*Q*<sub>L</sub>\| = *nRT*<sub>L</sub> ln(*V*<sub>c</sub>/*V*<sub>d</sub>)(Eq. 19.2.10), *W* = \|*Q*<sub>H</sub>\| − \|*Q*<sub>L</sub>\|(Eq. 20.2.1). 한 순환의 엔트로피 변화는 0이다(Eq. 20.2.2, 20.2.3) |
| 효율과 성능 계수 | *ε* = *W*/\|*Q*<sub>H</sub>\| = 1 − *T*<sub>L</sub>/*T*<sub>H</sub>(Eq. 20.2.4, 20.2.6), *K* = \|*Q*<sub>L</sub>\|/\|*W*\| = *T*<sub>L</sub>/(*T*<sub>H</sub> − *T*<sub>L</sub>)(Eq. 20.3.1, 20.3.3) |
| 작동 물질 | 교재는 정하지 않았다. 단원자 이상 기체(*C*<sub>V</sub> = 3*R*/2, Eq. 19.7.7, *C*<sub>p</sub> = *C*<sub>V</sub> + *R*, Eq. 19.7.13, *γ* = 5/3)로 두고 상태 a의 부피를 10 L로 정했다. 엔트로피는 Eq. (20.1.4)로 구하고 상태 a를 0으로 잡았다 |
| 범위 | 기관 *T*<sub>H</sub> 400–800 K, *T*<sub>L</sub> 250–380 K. 냉동기 방 280–320 K, 냉동실 240–275 K. *n* 0.5–2 mol, *V*<sub>b</sub>/*V*<sub>a</sub> 1.5–3. *R* = 8.31 J/mol·K |
| 재생 | 등온 과정 2 s, 단열 과정 1.5 s, 실린더 옮기기 0.4 s로 한 순환이 8.6 s이고 되풀이한다. 한 과정 안에서 ln *V*가 시간에 비례한다. 재생 시간은 과정의 순서만 보인다 |
| 채점 | 2% 또는 0.01 안이면 정답이고 *ε*는 소수나 %를 모두 받는다. *ε*에서 *T*<sub>L</sub>/*T*<sub>H</sub>, (*T*<sub>H</sub> − *T*<sub>L</sub>)/*T*<sub>L</sub>, 온도를 바꾼 1 − *T*<sub>H</sub>/*T*<sub>L</sub>을, \|*Q*<sub>L</sub>\|에서 0(완전 기관), \|*Q*<sub>H</sub>\|, \|*Q*<sub>H</sub>\|*T*<sub>H</sub>/*T*<sub>L</sub>, *W*를 따로 알려 준다. *K*에서 *T*<sub>H</sub>/(*T*<sub>H</sub> − *T*<sub>L</sub>), *T*<sub>L</sub>/*T*<sub>H</sub>, 1 − *T*<sub>L</sub>/*T*<sub>H</sub>, 뒤집은 비를, \|*W*\|에서 0(완전 냉동기), \|*Q*<sub>L</sub>\|*K*, \|*Q*<sub>L</sub>\|, \|*Q*<sub>H</sub>\|를 따로 알려 준다 |
| 시험 | `model.test.js` 7개. Sample Problem 20.2.1, 20.2.2, 단열선의 *TV*<sup>*γ*−1</sup>과 *pV*<sup>*γ*</sup>, \|*Q*<sub>H</sub>\|/*T*<sub>H</sub> = \|*Q*<sub>L</sub>\|/*T*<sub>L</sub>, 재생 경로를 따라 사다리꼴로 적분한 ∮*p dV* = ±*W*, 매 순간 Δ*E*<sub>int</sub> = *Q* − *W*, 냉동기의 *K* 세 표현과 열의 방향, 실린더 위치의 연속, 채점 |

Sample Problem 20.2.1은 이 모델에서 *W* = *nR*(*T*<sub>H</sub> − *T*<sub>L</sub>) ln *r*이 1200 J이 되도록 *n* = 1 mol, *r* = 1.300을 골라 시험한다. *ε* = 0.647, Δ*S* = ±2.18 J/K는 교재와 같다. 교재는 반올림한 *ε* = 0.647로 \|*Q*<sub>H</sub>\| = 1855 J을 구했고 반올림하지 않으면 1854.5 J, \|*Q*<sub>L</sub>\| = 654.5 J이라 시험은 정수로 반올림해 1855 J, 655 J과 비교한다. Sample Problem 20.2.2(물의 끓는점과 어는점 사이, *ε*<sub>C</sub> = 0.268)도 시험한다. 두 문제 값은 화면 기본값으로 쓰지 않았다(기관 500 K와 300 K, 냉동기 300 K와 250 K). 영어 용어(Carnot engine, Carnot refrigerator, insulating slab, efficiency, coefficient of performance, perfect engine, perfect refrigerator)는 교재 `c19`, `c20`에서 확인했다.
