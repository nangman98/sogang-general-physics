# 20-3 상자 속 분자의 배치 수와 엔트로피

교재 Principles of Physics 12e, Chapter 20, Module 20.4 A Statistical View of Entropy 화면이다. 상자의 두 반에 나뉜 분자의 배열마다 배치 수 *W*를 세고 미시 상태가 모두 같은 확률일 때 배열의 확률과 엔트로피 *S* = *k* ln *W*를 구한다. 활동은 둘이고 둘 다 재생 전에 예측하고 채점한다.

| 활동 | 학생이 하는 일 | 교재 대응 |
|---|---|---|
| 배치 수 세기 | 분자 수 *N*(2–12)과 배열 (*n*<sub>1</sub>, *n*<sub>2</sub>)를 고른다. 그 배열의 배치 수 *W*와 확률(%)을 적는다. 재생하면 미시 상태 스냅샷이 쌓이며 나온 비율이 확률에 다가간다 | Eq. (20.4.1), Table 20.4.1, Sample Problem 20.4.1, LO 20.4.1–20.4.3 |
| 퍼지는 분자 | 분자 수 *N*(10–1000)을 정한다. 왼쪽 반에만 있던 분자가 상자 전체로 퍼질 때 배열 (*N*, 0)에서 (*N*/2, *N*/2)로 바뀌는 엔트로피 변화를 10⁻²³ J/K 단위로 적는다 | Eq. (20.4.1)–(20.4.3), (20.4.5), Sample Problem 20.4.2, LO 20.4.4 |

## 모델

| 항목 | 내용 |
|---|---|
| 배치 수 | *W* = *N*!/(*n*<sub>1</sub>! *n*<sub>2</sub>!)(Eq. 20.4.1). 작은 *N*은 곱으로 정확히 세고 큰 *N*은 ln *N*!을 로그의 합으로 구한다 |
| 확률 | 미시 상태 2<sup>*N*</sup>개가 모두 같은 확률이므로 배열의 확률은 *W*/2<sup>*N*</sup>이다. 교재에 번호 붙은 식은 없고 Table 20.4.1의 합 64와 본문의 20/64에서 쓴 계산이다 |
| 엔트로피 | *S* = *k* ln *W*(Eq. 20.4.2), *k* = 1.38 × 10⁻²³ J/K(Eq. 19.2.3). 처음 배열 (*N*, 0)은 *W* = 1이라 *S*<sub>i</sub> = 0이다. 큰 *N*에서 Stirling 근사(Eq. 20.4.3)로 *S*<sub>f</sub> − *S*<sub>i</sub> = *Nk* ln 2(Eq. 20.4.5) |
| 스냅샷 | 1 s에 10장, 모두 500장(50 s). 장마다 분자가 각각 ½ 확률로 왼쪽이나 오른쪽에 놓인다. 시드를 고정한 의사난수로 미리 정해 두고 나온 배열의 누적 개수를 앞에서부터 더한다. 500장 뒤 *N* = 2, 6, 8, 12에서 나온 비율과 *W*/2<sup>*N*</sup>의 차가 0.05보다 작다 |
| 퍼짐 | 0.5 s에 칸막이를 치우고 8 s 동안 재생한다. 분자는 서로 부딪치지 않고 벽에서 거울 반사하는 직선 운동이며 시드를 고정한 처음 위치와 속도로 닫힌 식을 쓴다. 3–8 s 동안 *n*<sub>1</sub>/*N*의 평균이 *N* = 40, 200, 1000에서 0.5와 0.06 안이다 |
| 채점 | 2% 또는 0.01 안이면 정답이고 확률은 %나 소수를 모두 받는다. *W*에서 *N*!/*n*<sub>1</sub>!(한쪽만 나눔), *N*!, 2<sup>*N*</sup>을, 확률에서 배열마다 같다고 본 1/(*N* + 1), 미시 상태 하나의 1/2<sup>*N*</sup>을, 엔트로피에서 Stirling 근사 *Nk* ln 2, 상용로그, *k*를 빠뜨린 ln *W*, J/K로 적은 값을 따로 알려 준다. Stirling 값은 *N* = 220부터 2% 안에 들어 정답이 된다 |
| 시험 | `model.test.js` 6개. Table 20.4.1(*W*, 합 64, *S* 0, 2.47, 3.74, 4.13 × 10⁻²³ J/K, 확률 0.313, 0.016), Sample Problem 20.4.1(1.01 × 10²⁹, 1), Sample Problem 20.4.2(Stirling으로 *Nk* ln 2, 1 mol에서 5.76 J/K, 정확한 값과의 차가 *N*과 함께 줄어듦), 스냅샷 비율과 재현성, 퍼짐(열기 전 모두 왼쪽, 연 순간 위치가 이어짐), 채점 |

Table 20.4.1과 Sample Problem 20.4.1, 20.4.2의 값은 시험에만 쓰고 화면 기본값은 *N* = 8과 (3, 5), 퍼지는 분자 *N* = 40이다. *W*는 화면 목록에서 정한 이름대로 "배치 수 (multiplicity)", configuration은 "배열", microstate는 "미시 상태"로 쓴다. 영어 용어(configuration, microstate, multiplicity, Stirling's approximation, Boltzmann's entropy equation)는 교재 `c20`에서 확인했다.
